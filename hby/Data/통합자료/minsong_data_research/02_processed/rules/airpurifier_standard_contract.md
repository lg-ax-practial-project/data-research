- 작성: 김민송(QA) / 2026-10-13
- 목적: 팀이 **시연 계약 한 가지**를 정할 수 있도록 공식 화면 값과 규칙을 한 곳에 정리 (부용 님 "팀 결정 필요" 항목 지원)
- 근거: LG10(상품 화면 12개 조합), LG01·LG02(위약금·회수비), LG09(명의 변경), KCA01(의무사용기간=계약기간)
- ⚠ 금액은 2026-10-13 확인일 기준. 실제 적용은 계약서 기준

## 4. 계산 예시 – 후보 A, 18개월 사용 후 해지 [Mock 계약]
- 남은 기간: 36 − 18 = 18개월 / 경과 1년 이상 2년 미만 → 요율 20%
- 위약금 = 52,900 × 18 × 20% = **190,440원**
- 회수비 = 39,000원 (2026-03-24 기준 금액을 가상 계약에 적용한다고 가정)
- 예상 해지 비용 = **229,440원** (사은품·미납 없음 가정)
- 비교: 계속 사용(이사 후 주소 변경) 시 남은 구독료 = 52,900 × 18 = 952,200원 → 일회성 비용과 향후 구독료는 **구분해서** 안내

## 5. 확인 필요 (고객센터 P1~P5와 연결)
- 위약금 기준 "할인 전 기본요금"이 화면 표시 요금과 같은지 (이 모델은 할인 표시 없음)
- 의무사용기간 = 계약기간인지
- 회수비 35,000/39,000원 전환 시점 (P1)
- 이사 후 방문관리 불가 지역이면 위약금·타입 변경 처리 (P2)
