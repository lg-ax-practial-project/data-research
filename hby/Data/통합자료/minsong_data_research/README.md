# DataResearch · minsong

LG전자 CX 핵심 프로젝트 **"LG Move Care"의 근거 자료를 조사·검수하는 브랜치**입니다.

이사를 앞둔 **LG 공기청정기 구독 고객**이 해지·명의 변경·주소 변경 중 무엇을 할지 **쉽게 결정하도록 돕는** AI Agent에 필요한 공식 근거 자료를 정리합니다.
출처와 기준일이 확인된 자료만 관리합니다.

- 담당: 김민송 (자료조사 · QA)
- 관점: LG전자 CX 조직에 AI 서비스를 제안하는 개발회사
- **2026-10-13 주제 변경: 워시타워 → 공기청정기.** 워시타워 전용 자료는 `99_archive_washtower/`에 보관했습니다.

> 공기청정기 상품·케어·약관·이전 요금 등 **공기청정기 전용 공식 자료는 부용 님(hby) 브랜치**에 정리되어 있습니다.
> 이 브랜치는 ① 품목 공통 규정, ② 이사 상황 통계, ③ QA(수치·표현 검증), ④ LG 고객센터 확인을 맡습니다.
> 실제 서비스 구현 코드는 `cx-agent` Repository에서 관리합니다.

## 주요 내용

- **품목 공통 LG 규정**: 중도해지 위약금(30/20/10%), 사은품 비용, 해지 절차, 소유권, 청약철회, 명의 변경·실사용자 주소 변경
- **공기청정기 회수비 원문 대조**: 39,000원(2026-03-24 기준) / 35,000원(2021-11-05 계약부터) – 전환 시점은 확인 필요
- **공기청정기는 무상 철거·재설치 대상이 아님** (LG 공식 대상 목록 근거)
- **공기청정기 표준 계약 조건**: AS192DSFAM 계약기간 3~6년 × 케어 주기 3종 = 12개 요금 조합, 시연 계약 후보 3개와 해지 비용 계산 예시
- **한국소비자원 「가전 구독·렌탈 서비스 실태조사」 원문 수치 검증** (표현 수정 2건)
- **공공데이터 피해구제 분석**: 공기청정기 렌탈 12건 중 해지·위약금 8건 (2026년 2분기)
- **이사 상황 통계**: 25~29세 이동률 25.9%, 임차가구 평균 거주 3.6년 (팀에서 이 브랜치에만 있음)
- **LG 고객센터 확인**: 부용 님 조사에서 남은 "LG 확인 필요" 항목을 전화로 확인 (진행 중)

## 실제 데이터 / Mock 데이터 구분

- **실제 데이터**: LG전자, 한국소비자원, 공공데이터포털, 정부기관 공식 자료만 사용합니다. 금액·규정은 기준일을 함께 기록합니다.
- **상담 확인**: LG 고객센터 전화 답변은 "LG전자 고객센터 전화 상담(날짜)"로 표시하고, 웹 원문과 구분합니다.
- **참고용**: LG AI Chat 답변은 공식 근거로 쓰지 않습니다.
- **Mock 데이터**: 파일명과 표에 `[Mock]`을 붙입니다.
- 원문에서 확인하지 못한 내용은 **"확인 필요"**로 표시합니다.
