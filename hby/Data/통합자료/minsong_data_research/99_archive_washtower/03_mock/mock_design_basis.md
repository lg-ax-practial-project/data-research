> 목적: 실제 소비자 문제를 입증하는 것이 아니라, LG 내부 시스템과 Agent 실행 환경을 재현하는 것.

## 2. 이전 견적 [Mock] 계산 규칙 (제안)
- 무상 혜택 남음: 철거 0 + 재설치 0 + 운송비(거리)
- 무상 혜택 사용 완료: 철거 97,000 + 설치 134,000 + 운송비(거리) (LG05 요금)
- 운송비: 10km 미만 40,000 / 10~100km 미만 40,000 + 10km 구간당 20,000 / 100km 이상 220,000 + 10km 구간당 10,000
- 구간 올림 방식은 원문에 없음 → **[Mock] 가정** (10~19km = 1구간)
- 검산: `02_processed/rules/calc_check.py`
