## [R01] 해지할 때 내는 비용의 종류
- 의무사용기간 안에 해지: 위약금 + 회수비(회수 못 하면 분실료) + 사은품 비용 + 미납/연체 비용 등
- 의무사용기간은 끝났고 계약기간이 남았을 때 해지: 회수비만 (위약금 없음)
- 계약기간을 다 채우면: 해지 비용 없이 만기 후 소유권이 고객에게 이전
- 출처: LG01(가전 구독 서비스 안내), LG02(고객지원 FAQ) / 기준일: 페이지 표기 없음, 확인일 2026-10-12

## [R02] 위약금 계산 방법
- 남은 의무사용기간의 총 요금 × 요율. 월 요금은 **할인 전 기본요금** 기준
- 요율: 1년 경과 이전 30% / 1년 경과 후 2년 경과 이전 20% / 2년 경과 후 의무사용기간 이전 10%
- 계약기간 2년 상품: 1년 경과 이전 20% / 1년 경과 후 10%
- 약관 제13조 산식(한국소비자원 보고서 인용): (가전 구독 월요금 ÷ 30일) × (의무사용일수 − 실사용일수) × 요율 → 실제 정산은 일 단위
- 출처: LG01, LG02, KCA01 p.25 / 확인일 2026-10-12

## [R03] 워시타워 회수비
- 워시타워 회수비 111,000원 (2026년 3월 24일 기준)
- 회수비는 인건비 + 운송비이며, 실제로는 **계약서에 적힌 금액**을 따름
- 의무사용기간이 지났어도 계약기간 안에 해지하면 회수비가 부과됨
- 출처: LG02 (기준일 2026-03-24), LG01

## [R04] 사은품 비용
- 계약 성립 후 12개월 이내에 고객 요청으로 해지하면 받은 사은품 금액 전액이 부과됨
- 현금성 사은품은 액면금액, 비현금성 사은품은 LG전자 구매단가 기준
- 출처: LG01 / 확인일 2026-10-12

## [R05] 그 밖의 정산 항목
- 미납·연체비용, 잔여 비용(해약 시점까지 월 요금 일할), 제품 사용료(장기 미납만), 약정 할인 환불액, 선납 반환금
- 실제 해지비용은 해지 신청 후 상세 금액을 안내받음
- 출처: LG01 / 확인일 2026-10-12

## [R06] 이사할 때 무상 철거·재설치
- 워시타워는 무상 철거·재설치 대상. **가전 구독 계약기간 내 1회**
- 워시타워는 기존 설치 **철거도 무상 지원**
- **제품 이동(운송) 서비스는 포함되지 않음** → 운송비는 별도(고객 부담)
- 출처: LG01, LG03(워시타워 상품 페이지), LG07(베스트샵, 2026년 4월 기준)

## [R07] 이전설치 서비스 진행 방식
- LG전자 협력사 LX판토스의 설치 전문 기사가 철거 → 포장 → 이동 → 설치 위치 확인 → 설치 → 작동 확인 → 정리
- 접수: 홈페이지·앱·콜센터(1544-7777)
- 기사 방문 후 설치환경을 보고 작업 내용·시간·비용을 안내하며, 비용이 바뀔 수 있음
- 출처: LG04 / 확인일 2026-10-12

## [R08] 이전설치 운송비와 추가 비용
- 운송비: 10km 미만 40,000원 / 10~100km 미만 40,000원 + 10km당 20,000원 / 100km 이상 40,000원 + 180,000원 + 10km당 10,000원
- 제주–내륙 간은 별도 운임, 일부 장거리 지역 간은 이동 불가, 장거리는 당일 완료가 안 될 수 있음
- 사다리차 등 특수 장비 비용은 고객 부담, 필요한 부자재 구매가 필요할 수 있음
- 기사 방문 후 단순변심이나 설치불가로 작업을 못 하면 출장비(일반가전 25,000원)
- 출처: LG04, LG05(LX판토스 요금표, 기준일 표기 없음) / 확인일 2026-10-12

## [R09] 무상 혜택을 이미 쓴 경우 (일반 이전설치 요금)
- 워시타워 일반 이전설치: 철거 97,000원 + 설치 134,000원 + 기본운송 40,000원 = 271,000원 (10km 미만)
- 출처: LG05 (기준일 표기 없음, 확인일 2026-10-12)

## [R10] 새집에 워시타워를 놓을 수 있는지 미리 확인하기
- 수도꼭지가 옆에 있으면 가로 850mm 이상, 뒤에 있으면 가로 1,050mm·세로 2,000mm 이상 + 한쪽 300mm 통행 공간 필수
- 본체 깊이 830mm, 문을 다 열면 1,480mm 필요
- 벽돌 위·강화마루 위처럼 진동이 생기는 바닥은 설치가 안 될 수 있음
- 엘리베이터·현관문·창문 등 반입 경로가 제품보다 커야 함
- 간격은 권장 사항이며, 기사가 현장에서 보고 안전하면 설치할 수 있음
- 이전설치를 위해 고객이 요청하는 사전 답사는 25,000원
- 출처: LG06 / 확인일 2026-10-12

## [R11] 해지 신청 절차
- 해지 비용 확인 → 계약 조건 확인·상담 → 해지 신청(마이페이지 > 구독관리 > 계약관리 또는 1544-7777) → 비용 안내·동의 → 제품 회수·최종 정산
- 출처: LG01 / 확인일 2026-10-12

## [R12] 소유권과 계약 만료
- 계약기간 동안 소유권은 LG전자, 계약기간이 끝나고 미납이 없으면 고객에게 이전
- 3년 약정 상품은 종료 시 일반 판매가의 10%를 내고 소유권을 가져가거나 반납 중 선택
- 구독 중에는 구매(인수)로 전환할 수 없고, 다른 제품으로 교체할 수 없음
- 출처: LG01 / 확인일 2026-10-12

## [R13] 청약철회
- 매장·온라인 구매 7일, 방문판매 14일 이내 가능. 단, 워시타워처럼 설치가 필요한 제품은 **설치 완료 후 청약철회 불가**
- 출처: LG01 / 확인일 2026-10-12

## [R14] 이사할 때 워시타워를 직접 분리·운반해도 되나요?
- 워시타워의 설치와 분해는 **LG 전문 설치기사를 통해 이전 설치**해야 함 (고객지원 안내)
- 세탁기와 건조기를 결합하면 무게가 약 150kg이고, 전용 부자재(롤러 스택 가이드)가 필요하며, 넘어지면 다칠 수 있음
- 구독 고객은 계약기간 내 1회 무상 철거·재설치를 이용할 수 있음 (운송비 별도, R06 참고)
- 출처: LG08 (게시일 2026.05.29), LG01

## [R15] 이사할 때 해지·이전 말고 다른 방법은? (명의 변경)
- 계약자 이름을 다른 사람으로 바꾸려면 **명의 변경**을 해야 함. 계약자가 고객센터(1544-7777)로 직접 신청
- **설치일 기준 1년 이내에는 명의 변경 불가** (가족·실사용자 사이도 동일)
- 1년 이내라도 예외: 계약자 사망, 원수부적합, **해외이주, 도서지역 이사**
- 회사 신용심사 기준에 미달하면 명의 변경이 안 될 수 있음
- 명의 변경 시 위약금·회수비 처리 여부는 공식 안내에 없음 → 확인 필요
- 출처: LG09 (가전 구독 FAQ) / 확인일 2026-10-12

## [R16] 이사 후 주소·실사용자 정보 바꾸기
- 실사용자(인수자)의 이름·연락처·주소는 [마이페이지] > [구독 관리] > [계약 관리] 또는 고객센터에서 변경 가능
- 실사용자 정보만 바뀌는 것이고, 계약기간 중 책임과 의무는 계약자에게 있음
- 계약자가 아닌 사람(배우자 포함)은 계약 상담을 받을 수 없음 → 계약자가 먼저 실사용자 등록을 해야 실사용자가 이전설치 접수 등을 할 수 있음
- 이전설치 예약 조회: 마이페이지 > 이전설치 예약 현황
- 출처: LG09, LG04 / 확인일 2026-10-12

## Agent 답변 원칙 (QA 권고)
1. 금액은 항상 **"예상 금액"**으로 말하고, 최종 금액은 계약서·고객센터 기준이라고 함께 안내
2. 해지 비용(일회성)과 이전 시 계속 내는 월 구독료를 **구분**해서 안내. "이전이 ○○원 이득"이라고 단정하지 않기
3. 계약 정보와 규정이 맞지 않거나, 12·24개월 경계일이면 계산하지 말고 **"확인 필요"**로 전환
4. 설치 가능 여부는 단정하지 말고 **"기사 현장 확인 필요"**
5. 근거 없는 위약금·회수비 면제 약속 금지
6. 이전설치 비용 중 Mock 견적은 화면에 **[Mock]** 표시
