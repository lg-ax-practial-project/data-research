# Resources

가전 A/S 해결기준 안내 AI Agent 개발에 필요한 **공식 문서, 기준 데이터, 사례 및 조사 자료**를 관리하는 디렉토리입니다.

본 폴더의 자료는 데이터 분석 목적이 아니라,
Agent의 **RAG 검색, Tool 판정/계산, 테스트 및 평가**에 활용하기 위해 수집합니다.

---

## 1. MVP 조사 범위

현재 MVP에서는 전체 가전제품을 대상으로 하지 않고 아래 범위부터 조사합니다.

### 대상 제품

- 냉장고
- 세탁기
- 에어컨

### 대상 A/S 상황

- 동일 하자 반복
- 수리 지연
- 부품 미보유 / 수리 불가

MVP 완성 후 필요에 따라 제품과 상황을 확장합니다.

---

## 2. 우선 조사 자료

### 1) 소비자분쟁해결기준

가전제품과 관련된 공식 소비자분쟁해결기준을 수집합니다.

우선 확인할 내용:

- 품질보증기간
- 동일 하자 반복 관련 기준
- 수리 불가능 관련 기준
- 수리 지연 관련 기준
- 부품 미보유 관련 기준
- 교환 조건
- 환급 조건
- 감가상각 관련 기준

Agent가 답변의 공식 근거를 검색하는 **RAG 데이터**와
판정 규칙을 만드는 **Tool 데이터**의 기준 자료로 활용합니다.

---

### 2) 제품별 기간 및 수치 기준

냉장고, 세탁기, 에어컨에 대해 다음 정보를 조사합니다.

- 품질보증기간
- 부품 관련 기간
- 내용연수
- 기타 판정에 필요한 기간/수치

이 데이터는 주로 Agent의 기간 확인 및 계산 Tool에서 사용합니다.

---

### 3) 상황별 해결기준

다음 상황에서 어떤 조건에 따라 수리·교환·환급 등의 기준이 적용되는지 조사합니다.

#### 동일 하자 반복

확인할 정보 예시:

- 동일 하자 판단 기준
- 수리 횟수
- 품질보증기간
- 수리 / 교환 / 환급 조건

#### 수리 지연

확인할 정보 예시:

- 수리 지연 판단 기준
- 수리 의뢰일
- 경과 기간
- 적용 가능한 해결기준

#### 부품 미보유 / 수리 불가

확인할 정보 예시:

- 부품보유 관련 기준
- 수리 불가능 판단 조건
- 사용 기간
- 교환 / 환급 관련 기준

---

### 4) 환급 및 감가상각 기준

예상 환급액 계산 Tool 개발에 필요한 자료를 조사합니다.

확인할 내용:

- 환급액 계산 공식
- 구입가 적용 방법
- 사용기간 계산 방법
- 내용연수
- 감가상각 기준
- 추가 가산/공제 규정
- 예외 조건

계산식과 숫자는 임의로 작성하지 않고 반드시 공식 출처를 확인합니다.

---

### 5) 공식 상담 사례 / 표준답변

실제 소비자가 어떤 방식으로 질문하는지 파악하고 Agent 평가 데이터를 만들기 위해 관련 사례를 수집합니다.

예시:

- 같은 고장으로 여러 번 수리한 사례
- 수리가 장기간 지연된 사례
- 부품이 없어 수리가 불가능한 사례
- 교환/환급 가능 여부를 문의한 사례
- 예상 환급액을 문의한 사례

해당 자료는 주로 **RAG 보조자료 및 Agent Evaluation 데이터**로 활용합니다.

---

## 3. 데이터 활용 구분

수집한 자료는 용도에 따라 다음과 같이 구분합니다.

### RAG

공식 근거를 검색하기 위한 자료입니다.

예:

- 소비자분쟁해결기준 원문
- 관련 조항
- 공식 해설
- 공식 표준답변
- LG전자 공식 A/S 관련 자료

> RAG의 역할: **관련 공식 근거를 찾는다.**

### Tool

정확한 조건 확인 및 계산에 사용되는 구조화 가능한 데이터입니다.

예:

- 품질보증기간
- 부품 관련 기간
- 내용연수
- 동일 하자 반복 조건
- 수리지연 조건
- 환급 계산 공식

> Tool의 역할: **사용자 조건을 기준과 비교하고 계산한다.**

### Evaluation

Agent의 동작을 검증하기 위한 사례 데이터입니다.

예:

- 정상적인 A/S 문의
- 정보가 부족한 문의
- 여러 조건이 포함된 문의
- Agent 지원 범위를 벗어난 문의

## 4. 자료 조사 원칙

### 공식 출처 우선

가능하면 다음과 같은 공식 출처의 자료를 우선합니다.

- 공정거래위원회
- 한국소비자원
- 국가법령정보센터 등 공공기관
- LG전자 공식 홈페이지 / 고객지원

블로그, 카페, 개인 게시글 등은 공식 기준의 근거 자료로 사용하지 않습니다.

### 원본 보존

PDF, CSV, XLSX 등 다운로드한 원본 파일은 임의로 수정하지 않습니다.

가공이 필요한 경우 원본과 가공 데이터를 구분하여 관리합니다.

### 출처 기록

자료를 추가할 때 최소한 다음 정보를 함께 기록합니다.

- 자료명
- 출처 기관
- 원본 URL
- 게시일 / 시행일 / 기준일
- 확인일
- 관련 제품
- 관련 상황
- 활용 목적 (RAG / Tool / Evaluation)
- 관련 페이지 또는 조항

### 임의 해석 금지

공식 자료에서 명확하게 확인되지 않는 내용은 임의로 규칙화하지 않습니다.

애매한 내용은 다음과 같이 표시합니다.

> `확인 필요`

## 5. 디렉토리 구조

초기에는 다음 구조를 기준으로 관리합니다.

resources/
├── README.md
├── raw/
│   ├── consumer_dispute/
│   ├── lg_service/
│   └── official_cases/
│
└── processed/
    ├── rag/
    ├── rules/
    └── evaluation/

### raw/

수집한 원본 자료를 보관합니다.

원본 파일은 가능한 한 수정하지 않습니다.

### processed/rag/

RAG 검색을 위해 전처리한 데이터를 저장합니다.

### processed/rules/

기간, 판정 조건, 계산식 등 Tool에서 사용할 수 있도록 구조화한 데이터를 저장합니다.

### processed/evaluation/

Agent 테스트 및 평가에 사용할 질문과 시나리오를 저장합니다.

## 7. 현재 목표

현재 단계의 목표는 자료를 최대한 많이 수집하는 것이 아닙니다.

**냉장고·세탁기·에어컨의 대표 A/S 상황에 대해 Agent가 실제로 검색·판정·계산할 수 있는 최소 데이터를 확보하는 것**이 목표입니다.

우선 아래 흐름을 구현할 수 있는 데이터 확보를 우선합니다.

사용자 질문
→ 필요한 정보 확인
→ 공식 기준 검색
→ 기간/조건 확인
→ 적용 가능한 해결기준 확인
→ 필요 시 예상금액 계산
→ 근거 및 다음 행동 안내

MVP에 필요한 데이터가 확보된 이후 추가 제품 및 A/S 상황으로 확장합니다.
