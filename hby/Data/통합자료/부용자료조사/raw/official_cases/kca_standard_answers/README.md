# 한국소비자원 품목별 피해구제사례 HTML 원본

- 수집 형태: 한국소비자원 `품목별 피해구제사례`의 여러 공식 답변을 검색어별로 모아 노션에서 HTML로 내보낸 파일
- 열람일: 2026-09-28
- 공식 목록: https://www.kca.go.kr/odr/cm/in/exmplPgItem.do?brdId=00000006&dataStts=Y&multiItmSeq=8
- 원본 보존: HTML 7개를 내용 수정 없이 보관
- HTML 7개에는 총 23개 항목이 있으나 검색어가 겹쳐 같은 답변이 여러 파일에 중복 수록됨

## 정제 결과

- MVP 관련 고유 표준답변: 12건
- 범위 밖 고유 표준답변: 6건
- 둘 이상의 파일에 중복 수록된 제목: 4건

### MVP 관련

- 중고에어컨의 품질보증 가능 여부 — 에어컨 / 부품 미보유·수리 지연 / 핵심
- 냉장고 소음이 심하여 신경이 쓰이는 경우 — 냉장고 / 소음 하자 입증 / 보충
- 소비자과실로 발생한 에어컨 고장 수리 불가능한 경우 — 에어컨 / 부품 미보유·수리 불가 / 핵심
- 에어컨 수리는 하지 않고 할부금만 독촉하는 경우 — 에어컨 / 반복 고장·수리 지연 / 핵심
- 에어컨 배달시 파손된 경우 보상여부 — 에어컨 / 배송 중 파손 / 보충
- 인터넷으로 구입한 청소기, 광고와 다른 경우 반품비용 부담 여부 — 청소기 / 표시·광고와 다른 성능 / 보충
- 방문판매원이 시험사용 후 인도한 진공청소기의 청약철회 여부 — 청소기 / 방문판매 청약철회 / 보충
- 전기진공청소기를 방문판매로 충동 구매한 경우 — 청소기 / 방문판매 청약철회 / 보충
- 해외구매대행사이트에서 구입 후 배송과정에서 파손된 TV의 보상 가능 여부 — TV / 해외배송 중 파손 / 보충
- 할인 구매한 TV 교환시 차액을 추가 요구하는 경우 — TV / 하자 제품 교환 / 핵심
- 수리 지연되는 LCD TV 보상 방안 문의 — TV / 수리 지연 / 핵심
- TV 구입일의 확인이 불가능한 경우 품질보증기간 — TV / 품질보증기간 기산 / 핵심

### 범위 밖

- 3회 수리에도 하자 발생한 안마의자의 환급 가능 여부 — 제품 범위 밖(안마의자)
- TV홈쇼핑에서 구입한 표시광고와 다른 온돌침대 보상 요구 — 제품 범위 밖(온돌침대)
- 관리가 되지 않는 정수기 계약 해지 가능 여부 문의 — 제품 범위 밖(정수기)
- 노조 파업으로 A/S 지연된 정수기 렌탈서비스의 보상 여부 — 제품 범위 밖(정수기)
- 세탁기 수리 후 2개월만에 고장 재발하여 수리비를 요구하는 경우 — 제품 범위 밖(세탁기)
- 제조회사가 도산하여 전기포트 A/S를 거절하는 경우 — 제품 범위 밖(전기포트)

## 주의사항

- 이 자료는 소비자분쟁조정위원회의 조정 결정문이 아니라 한국소비자원의 상담형 공식 표준답변이다.
- HTML의 노션 생성일은 한국소비자원의 게시일·수정일이 아니다.
- 개별 상세페이지가 POST 방식이라 가공 데이터에는 공식 목록 URL과 항목 식별자(seq)를 함께 기록했다.
- 과거 답변에 나온 기간·비율·법 조문은 현행 기준과 대조하기 전까지 Tool 규칙으로 사용하지 않는다.
