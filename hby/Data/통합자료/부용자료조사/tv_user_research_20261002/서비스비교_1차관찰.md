# LG 기존 서비스 비교 — 1차 관찰

실행일: 2026-10-02. 방법: 비로그인 브라우저에서 공개 페이지·검색 UI를 직접 확인. 실제 고객 인터뷰 및 챗봇 대화 결과가 아니다.

이 문서의 ‘대화 0/6’은 사용자 응답 제공 이전 관찰 시점의 상태다. 이후 S01 첫 응답을 받아 부분 실행으로 갱신했으며 최신 대화 상태는 [S01_응답분석.md](S01_응답분석.md)와 README를 참고한다.

## 핵심 발견

**LG 공식 검색은 이미 증상 안내의 생성형 AI 요약과 근거 페이지 연결을 제공한다.** 따라서 ‘공식 문서를 찾아 요약하고 링크를 제공한다’만으로 프로젝트 차별화를 주장하지 않는다.

## 관찰 기록

| ID | 실행한 입력·경로 | 확인된 결과 | 해석의 한계 |
| --- | --- | --- | --- |
| WEB-01 | 고객지원 메인 검색에 ‘TV 화면은 안 나오고 소리만 나와요’ 입력 | 고객지원 검색 화면에 관련 결과 14개, 생성형 AI 요약 표시, 참고 페이지 링크 확인 | S01 전체 질문이 아닌 증상만 검색했다. 구입 8개월·첫 고장 조건 검토나 대화형 추가 질문은 테스트하지 않았다. 결과 수는 당일 해당 검색 결과 수다. |
| WEB-02 | 검색창에 ‘TV 11개월 영수증 없는데 무료 수리되나요’ 입력 | 통합검색 화면에 검색결과 없음 표시 | 고객지원 탭이 아닌 통합검색으로 이동했다. WEB-01과 경로가 다르므로 성공률 비교에 사용하지 않는다. 단일 입력에서의 관찰이며 LG가 보증 안내를 못 한다는 의미가 아니다. |
| DOC-01 | 공식 요금/보증 페이지의 보증기간 안내 탭 직접 열람 | 구입·배송일, 증빙 부재, 제품 보증과 핵심부품 보증, 구매·사용 형태 예외 안내 확인 | 특정 사용자의 무상 수리 가능 여부를 확정하지 않는다. 해당 문서 안내와 정부 기준 대조는 별도 작업이다. |

WEB-01 요약은 음량 표시 유무에 따른 외부기기 점검/전문 점검 분기, 전원을 끈 상태에서 HDMI 재연결, 조건에 맞는 셋톱박스 재시작을 안내했다. 참조된 공식 안내 본문과 주요 분기·전원 조치가 맞는지 대조했다. TV 모델 불명인 개인에게 그대로 적용 가능하다고 확정한 검증은 아니다.

## Agent 기능에 연결하는 법

| 구분 | 내용 |
| --- | --- |
| 이미 확인된 기존 기능 | 증상 검색, 자가 점검 분기, 생성형 AI 요약, 참고 페이지, 보증 정책 안내 |
| 아직 차별화라고 말할 수 없는 부분 | 개인별 조건 질문, 점검 결과 전달, 상담 준비물 정리, 수리 이력 재분석: 기존 챗봇·계정 기능 검증 미완료 |
| 구현·검증 후보 | 증상뿐 아니라 구입 증빙·모델·점검 결과를 누적해 확인/미확인 조건을 표시하고 상담 준비 요약을 만드는 흐름 |
| 검증할 성과 | 상담 준비 정보 누락 수, 필요한 추가 질문의 적절성, 근거 일치 여부, 반복 설명해야 하는 정보 수 |

이 표는 기능 제안이다. 실제 고객이 어렵다고 진술한 결과나 기존 서비스 대비 우수함을 입증한 결과가 아니다. 프로젝트 Agent 구현 전 성능 향상 수치를 만들지 않는다.

## 대화 진입 및 완료 상태

고객지원 메인과 검색 페이지의 AI Chat 링크로도 진입을 시도했지만 상담용 입력창·새 탭은 관찰되지 않았다. 검색 결과 본문이 뒤늦게 나타난 것을 AI Chat 응답으로 세지 않았다. 원인은 미확인이다.

- 공개 검색 실행 관찰: 2건
- 보증 안내 페이지·탭 재확인: 1건
- 실제 챗봇 시나리오 대화: 0/6건
- 인터뷰 참가자: 0명
- Agent와 기존 서비스의 동일 조건 성능 비교: 미실행

다음에는 일반 브라우저에서 AI Chat이 열리는지 사용자가 확인해 주면 준비한 동일 질문 6개를 대화로 비교한다. 로그인·개인정보·사람 상담이 필요한 경로는 이번 자동 비교에서 진행하지 않는다.
