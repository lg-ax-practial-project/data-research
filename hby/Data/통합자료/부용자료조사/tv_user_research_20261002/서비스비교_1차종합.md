# LG TV 기존 고객지원 — 1차 비교 종합

작성일: 2026-10-02. 대상: LG TV 가상 상황 6개. 목적: 기존 서비스가 제공하는 기능을 확인하고, 우리 Agent의 추가 검증 항목을 도출한다.

## 결론 먼저

**자가 점검 설명·보증 및 반복 고장 안내·증빙 목록·서비스 연결은 이미 제공되는 기능이다.** 우리 프로젝트의 차별화를 ‘이 정보를 챗봇으로 알려준다’로만 설명해서는 부족하다.

이번 테스트에서 확인한 제한적 단서는 미확인 조건을 먼저 해결하는 안내, 한 단계씩 결과를 확인하는 흐름, 주장과 링크의 일치, 질문한 조건 계산까지 연결하는 과정이다. 이를 바탕으로 **‘설명에서 끝나지 않고 확인한 정보·점검 결과·수리 이력을 다음 행동에 연결하는 상담 준비 Agent’**를 기능 가설로 제안한다. 참신함·효과·우수함이 입증됐다는 뜻은 아니다.

## 조사 방식과 자료 범위

- 사용자가 LG 챗봇에 가상 질문을 입력하고 응답을 이 대화에 제공했다. 6개 시나리오 첫 응답, 총 8개 응답을 보존했다.
- S01·S03은 각 2턴, S02·S04·S05·S06은 각 1턴이다.
- S02·S04·S05·S06은 실제 질문 문장 복사본도 확보했다. S01·S03의 실제 입력·후속 입력은 제안 질문과의 일치 미확인이다.
- 실제 챗봇 실행일·모델 버전·계정 상태·새/동일 세션·전체 화면·응답 시간은 확보하지 못했다. 기록일은 수신일이지 실행일이 아니다.
- 공식 LG 원문을 일부 대조했다. 공개 검색 2건·보증 탭 재확인 1건은 대화 응답과 별도 집계다.
- 실제 고객 인터뷰 0명, 실제 접수/교환 승인/환급 이행 0건, 프로젝트 Agent 동일 조건 성능 비교 미실행이다.

공백은 제공된 본문에서 관찰한 범위다. 기존 계정·예약·상담 시스템 전체에 기능이 없다는 의미는 아니다. 날짜나 원문 링크를 요청하지 않은 질문에서 이를 설명하지 않았다는 이유만으로 일괄 실패 판정하지 않았다.

## 공식 원문과 대조해 확인한 사실

- LG 검색은 생성형 AI 요약과 참고 페이지 연결을 제공했다. [공개 검색 관찰](서비스비교_1차관찰.md).
- S03의 첫 링크는 [공기청정 필터 신청](https://www.lge.co.kr/support/request-air-purifiers-filter-change?chatbot=y) 페이지로 열렸다. TV 파워보드 설명의 근거로 부적합했다. 파워보드 서비스나 모델 목록 자체가 허위라고 확인한 것은 아니다.
- [LG 보증 안내](https://www.lge.co.kr/support/rates-warranty-guide)는 구매 증빙 부재 시 보증 시작일 계산 조건을 명시한다. S03은 세부 계산을 유보했고 해당 조건을 설명하지 않았다. 임의의 계산식을 만든 응답은 아니었다.
- [이브닝 서비스 공지](https://www.lge.co.kr/support/notice-NTC20230914327001?chatbot=y)는 후속 응답의 서비스 설명과 맞지만 요청한 보증 정책 페이지는 아니다.
- [일반 리모컨 안내](https://www.lge.co.kr/support/solutions-20153029473451)에도 LED 확인이 기재돼 있다. 일반 리모컨 LED 설명을 일괄 오류로 평가하지 않았다. 셋톱박스 방식 예외와 모델별 조건은 구분해야 한다.
- [신호 없음 안내](https://www.lge.co.kr/support/solutions-1777960)는 리모컨 구분과 HDMI 재연결 전 전원 OFF 조건을 안내한다. S02 제공 본문에는 해당 식별 지원과 전원 OFF 조건이 설명되지 않았다.

LG 정책 확인과 정부 고시 현행 버전 검수는 별개다. 현재 Tool 규칙을 이 응답들에서 직접 추출해 확정하지 않는다.

‘필요가 있을 수 있음’은 실제 고객 인터뷰 결과가 아니다. 같은 기능이 기존 서비스에 있는지와 실제로 유용한지는 아직 검증해야 한다.

## 평가 기준 후보

1. 미확인 모델·날짜·원인을 추측해 채우지 않는가?
2. 접수·방문·실제 수리·재발을 구분하는가?
3. 같은 증상과 동일 하자를 구분할 추가 정보를 확인하는가?
4. 점검 경로가 제품/리모컨 조건에 맞고 안전 조건을 유지하는가?
5. 단일 단계 요청을 받으면 한 단계만 안내하고 해당 결과를 질문하는가?
6. 공식 링크가 설명한 제품·주장을 실제로 뒷받침하는가?
7. 근거가 있는 계산과 현장 진단이 필요한 판단을 구분하는가?
8. 고객이 물은 요청을 해결했는지, 해결 못 했다면 무엇이 부족한지 설명하는가?

이 기준은 평가 설계 후보이며 점수·성공률은 산출하지 않았다. 6개 가상 질문은 고객 모집 표본이 아니며 고장 빈도·일반 정확도·시장 차별성 추정에 쓸 수 없다.
