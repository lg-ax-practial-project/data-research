# 기존 LG 고객지원과 프로젝트 기능 가설

최신 결과: [서비스비교_1차종합.md](서비스비교_1차종합.md). 사용자 제공 응답 8턴·6개 시나리오의 1차 비교를 정리했다. 아래 표는 초기 문서 대조이며 최신 관찰은 종합 문서를 우선한다.

근거: 1·2차 수집에서 확인한 공식 본문과 공개 검색 관찰. 아래 표는 고객 사용성 테스트 결과가 아니다. 이후 사용자 제공 챗봇 첫 응답의 부분 분석은 [S01_응답분석.md](S01_응답분석.md)에 별도 기록했다.

| 기능 | 공식 문서에서 확인한 것 | 아직 확인하지 못한 것 | 프로젝트에서 검증할 제안 |
| --- | --- | --- | --- |
| 증상별 자가 점검 | 화면·신호·소리·리모컨 안내 있음 | 사용자 조건을 대화로 수집하는 수준 | 조건에 따라 점검 경로를 한 단계씩 안내 |
| AI 검색 요약·근거 연결 | 2026-10-02 고객지원 검색에서 생성형 AI 요약과 참고 페이지 확인 | 개인 조건 누적·후속 대응의 대화 처리 수준 | 단순 요약은 기존 기능으로 인정하고 상담 준비·연속 대응 검증에 집중 |
| 제품별 경로 | webOS·리모컨 종류별 조건이 일부 안내됨 | 모델 불명 상황에서 챗봇이 어떻게 처리하는가 | 불명 정보를 추측하지 않고 확인 경로 제공 |
| 보증·비용 | 증빙·기간·유상 사유·구매 형태 예외 안내 있음 | 개인별 조건을 대화에서 얼마나 검토하는가 | 확인/미확인 조건 카드 |
| 공식 접수 연결 | 상담·출장 예약 연결 및 제품군 선택 경로 있음 | 증상·점검 결과가 경로 간 이어서 전달되는가 | 상담 준비 요약과 공식 경로 연결 |
| 기록·후속 대응 | 이번 본문 검토로는 연속 이력 기능 확인 못함 | 기존 챗봇/계정 서비스의 기록·재분석 기능 | 사용자 입력 기반 접수/점검/수리/재발 기록 |

‘확인 못함’은 ‘기능 없음’이 아니다. LG에 이미 자가 점검·보증 안내·예약 연결이 있으므로 이것만으로 신선함이나 차별화를 주장하지 않는다.

## 근거 링크

- [OLED 화면 없이 소리](https://www.lge.co.kr/support/solutions-20152183148933): 음량 표시와 외부기기·전문 점검 분기
- [신호 없음](https://www.lge.co.kr/support/solutions-1777960): TV/셋톱박스, 입력, 버전별 경로
- [음향 자가진단](https://www.lge.co.kr/support/solutions-20150903914041): 진단 결과와 버전별 메뉴
- [일반 리모컨](https://www.lge.co.kr/support/solutions-20153029473451): 일반·매직·셋톱박스 리모컨 구분
- [요금/보증](https://www.lge.co.kr/support/rates-warranty-guide): 증빙·구매 형태·사용 조건·부품 보증
- [출장 예약](https://www.lge.co.kr/support/service-engineer-reservation): 모델명/제조번호 또는 제품군 선택, 증상·구입 시기 입력

## 실행 시도 기록

후속 공개 검색 관찰은 [서비스비교_1차관찰.md](서비스비교_1차관찰.md)에 추가했다. 대화 비교와 공개 검색 관찰의 집계는 분리한다.

2026-10-02, OLED 안내 페이지에서 AI Chat 진입 화면을 읽기 전용으로 확인하려고 시도했다. 메시지 제출·로그인·개인정보 입력·사람 상담·예약은 요청하지 않았다. 브라우저 상호작용 도구가 45초 시간 초과로 실패하여 결과 화면과 세션 식별자를 받지 못했다.

따라서 챗봇이 작동하지 않는다는 결론도, 챗봇의 기능이 부족하다는 결론도 내릴 수 없다. 기능 대조 결과 중 대화·이력·경로 간 전달 부분은 보류 상태다.
