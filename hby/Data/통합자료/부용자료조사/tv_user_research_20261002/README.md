# TV 고객 문제 검증 준비 및 기존 서비스 1차 비교

작성일: 2026-10-02.

**먼저 보기: [서비스비교_1차종합.md](서비스비교_1차종합.md).** 6개 시나리오의 첫 응답 수집과 1차 비교표 작성을 마쳤다. 실제 고객 인터뷰나 Agent 성능 검증 완료와 구분한다. 구조화 집계: processed/collection_status.json.

후속 팀 검토 준비 완료: [MVP 기능 선택안](../tv_mvp_review_20261002/MVP_기능선택안.md), [검수 목록](../tv_mvp_review_20261002/규칙_안전_검수체크리스트.md). 제안이며 팀 채택·담당자 지정·검수 승인은 미완료다. 새로운 인터뷰·챗봇 응답이 추가된 것은 아니다.

사용자 확인: 현재 인터뷰 대상자 없음. 실제 인터뷰는 대상자 모집·동의 확보 전까지 보류한다. 가상 테스트를 인터뷰 대체 결과로 보고하지 않는다.

## 현재 완료한 것과 미완료한 것

- 완료: 기존 공식 자료 기반 기능 대조표, 가상 비교 시나리오 6개, 인터뷰 질문·동의·익명 기록 양식.
- 시도했으나 미완료: LG 페이지의 AI Chat 진입 화면 확인. 브라우저 도구가 45초 시간 초과로 종료되어 화면·대화 결과를 확보하지 못했다. 세션 식별자도 반환되지 않았다.
- 후속 진입 시도(2026-10-02): 다른 브라우저 도구에서 공식 안내 페이지를 열고 AI Chat 버튼을 눌렀으나 접근성 화면 변화와 새 탭이 관찰되지 않았다. 질문은 제출하지 않았다. 현재 조사 환경에서 진입을 완료하지 못한 것이며, LG 챗봇의 고장이나 기능 부재를 입증한 결과가 아니다. 상세 기록: [챗봇_진입확인_20261002.md](챗봇_진입확인_20261002.md).
- 완료: 챗봇 6개 시나리오 첫 응답 수집, 총 8개 응답 보존, 개별 분석 6개, 공식 원문 일부 대조, 통합 비교표.
- 미완료/미실행: 전체 다중 턴 검증·실행 메타데이터 확인, 실제 인터뷰, 사람 상담, A/S 접수, Agent와 기존 서비스의 성능 비교.

**첫 응답 수집 6/6개, 총 응답 8턴, 실제 인터뷰 0명.** S01·S03 각각 2턴, 나머지는 각각 1턴이다. S02·S04·S05·S06은 질문 복사본도 확보했다. 실제 실행 시각·세션·전체 화면 등은 미확인이다. [S01](S01_응답분석.md), [S02](S02_응답분석.md), [S03](S03_응답분석.md), [S04](S04_응답분석.md), [S05](S05_응답분석.md), [S06](S06_응답분석.md). 지금은 질문을 더 늘리지 않고 팀의 기능 가설 선택·규칙/안전 검수·고객 검증 공백 정리로 넘어간다. 가상 테스트를 실제 고객 경험으로 일반화하지 않는다.
