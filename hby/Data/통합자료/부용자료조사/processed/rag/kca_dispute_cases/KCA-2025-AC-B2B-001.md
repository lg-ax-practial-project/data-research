# KCA-2025-AC-B2B-001 난방 성능 미흡에 따른 냉난방기 구입대금 환급 요구

- 사례 ID: KCA-2025-AC-B2B-001
- 제공 기관: 한국소비자원 소비자분쟁조정위원회
- 사건번호·결정일: 원문 미기재
- 게시 페이지 수정일: 2025-07-03

## 제품과 분쟁유형

- 제품: 산업용 냉난방기
- 주 유형: 소비자 해당 여부
- 보조 유형: 난방 성능 미흡, 실외기 동파, 용량 부족
- 활용 우선도: 평가셋용 범위 경계 사례

## 사실관계와 주장

- 신청인은 2022-07-11 회사에 냉난방기 3대와 에어컨 1대를 20,916,500원에 구입·설치했다.
- 냉난방기 1대의 난방기능 문제로 A/S를 요청했고, 기사는 실외기 동파를 안내했다.
- 신청인은 다른 실외기는 정상이고 토출 온도가 낮다는 점 등을 하자로 주장했다.
- 제조사는 제품 성능은 정상이며 동파와 공간 대비 용량 부족 문제라고 주장했다.

## 판단과 처리 결과

- 신청인은 온열의료기 제조·판매 사업자로, 공장·창고의 원단 보존이라는 생산활동을 위해 산업용 제품을 구입했다.
- 위원회는 신청인을 소비자와 같은 지위의 최종사용자로 보기 어렵고 소비자와 사업자 사이의 분쟁이 아니라고 판단했다.
- 결정: 조정하지 아니함.
- 적용 기준: 소비자기본법 제2조, 같은 법 시행령 제2조

## Agent 활용 및 확인 필요

- RAG·평가셋: 제품 하자 판단 전에 가정용인지, 사업·생산활동용인지 확인해야 하는 사례
- 추가 질문: 구입 주체, 설치 장소, 제품의 가정용·산업용 구분, 사용 목적
- 피해야 할 답변: 산업용 사업자 거래에도 소비자분쟁해결기준이 당연히 적용된다고 단정
- 냉난방기의 하자 유무 자체는 판단되지 않았으므로 성능 판정 규칙으로 사용하지 않는다.
