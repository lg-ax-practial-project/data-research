# KCA-2024-VC-RETURN-001 차량용 휴대용 청소기 청약철회에 따른 대금 환급 요구

## 기본정보

- 사례 ID: KCA-2024-VC-RETURN-001
- 제공 기관: 한국소비자원 소비자분쟁조정위원회
- 사건번호·결정일: 원문 미기재
- 게시 페이지 수정일: 2024-10-14
- 열람일: 2026-09-28
- 공식 원문: https://www.kca.go.kr/odr/bj/br/osBjDecisionExamDetW.do?dataStts=Y&brdId=00000007&seq=1003739529

## 제품과 분쟁유형

- 제품: 차량용 휴대용 청소기
- 주 유형: 광고된 환불보장 약정에 따른 환급
- 보조 유형: 테스트 사용, 청약철회 제한, 표시·광고
- 활용 우선도: 보충 사례(일반 가정용 청소기 A/S와는 구분)

## 사실관계와 주장

- 소비자는 2024-05-24 온라인에서 청소기를 57,400원에 구입하고 다음 날 수령했다.
- 2024-05-27 흡입력이 약하다며 청약철회를 표시했고, 청소에는 쓰지 않았지만 손바닥에 대고 작동시간을 측정했다고 밝혔다.
- 판매자는 필터 사용 흔적과 `14일 사용 후 3일 이내 신청` 조건을 이유로 환급을 거부했다.
- 판매페이지에는 흡입력 불만족 시 사용 후에도 100% 환불을 보장한다는 내용이 있었다.

## 판단과 처리 결과

- 테스트 사용으로 가치가 현저히 감소한 경우의 일반 청약철회는 인정하기 어렵다고 보았다.
- 다만 판매페이지의 환불보장 표시는 당사자 사이 계약 내용이며, 소비자가 그 표시를 신뢰해 구매했다.
- 기간 조건은 명확하게 필수 조건으로 표시됐다고 보기 어렵고 청약철회권을 제한할 우려도 있다고 판단했다.
- 판매자는 57,400원을 지급하고 지연 시 2024-10-24부터 당시 기준 연 6%를 가산하도록 결정됐다.
- 통신판매중개자에 대한 신청은 조정하지 않았다.

## Agent 활용 및 확인 필요

- RAG: 법정 청약철회와 사업자가 별도로 약속한 환불보장 제도를 구분
- 추가 질문: 사용 정도, 반품 신청일, 광고 화면, 환불보장 조건, 필터 상태
- 현행 전자상거래법과 광고 약정 해석 대조 필요
- 흡입력 불만을 곧바로 제품 하자나 A/S 불가로 분류하면 안 된다.
