# 한국소비자원 가전 분쟁조정 사례 정제 데이터

한국소비자원 소비자분쟁조정위원회 사례집과 공식 웹 원문에서 냉장고, TV, 청소기, 에어컨 관련 사례를 선별해 정리한 자료다.

## 구성

- `KCA-2018-KREF-001.md`: 김치냉장고 냉장 온도 하자 및 교환
- `KCA-2020-REF-001.md`: 반복 하자 냉장고의 감가상각 환급
- `KCA-TV-001.md`: 화질 불량 TV의 청약철회 및 환급
- `KCA-2020-RVC-001.md`: 작동 불량 로봇청소기의 청약철회
- `KCA-2018-AC-001.md`: 에어컨 실외기 시공 불량 손해배상
- `KCA-2020-VC-001.md`: 방문판매 청소기의 반품 및 환급
- `KCA-2021-TV-WARP-001.md`: 배송 당시 휘어진 TV의 청약철회
- `KCA-2025-AC-B2B-001.md`: 산업용 냉난방기 거래의 소비자 해당 여부
- `KCA-2018-AC-PERF-001.md`: 냉난방기 성능·용량·광고 분쟁
- `KCA-2018-TV-SVC-001.md`: 스마트 TV의 제3자 서비스 중단
- `KCA-2021-TV-PANEL-001.md`: 설치 직후 TV 패널 하자
- `KCA-2024-VC-RETURN-001.md`: 차량용 청소기의 광고상 환불보장
- `KCA-2021-TV-OVERSEAS-001.md`: 해외 구매대행 TV 청약철회
- `KCA-2023-TV-PARTS-001.md`: TV 부품 미보유로 인한 수리 불가
- `KCA-RELIEF-2025-AC-BULK-001.md`: 동일 오류 에어컨 수리비 일괄 조정
- `KCA-RELIEF-2025-SYSAC-001.md`: 시스템에어컨 냉방 성능 관련 시공환경 개선
- `KCA-RELIEF-2024-REF-CONTRACT-001.md`: 계약과 다른 냉장고 제공에 대한 계약 이행
- `cases.jsonl`: 위 사례를 RAG 적재용으로 합친 JSON Lines 파일
- `coverage.md`: 품목과 분쟁유형별 확보 현황 및 조사 공백

## 사용 원칙

1. `원문에서 확인된 사실`과 `조사자 정리`를 구분한다.
2. 소비자의 요구, 사업자의 제안, 조정 결정, 실제 이행 여부를 서로 바꾸어 쓰지 않는다.
3. 개별 사례의 결론을 모든 고객에게 적용되는 규칙으로 사용하지 않는다.
4. `현행 기준 대조 필요` 사례는 평가 정답이나 계산 Tool 규칙으로 확정하지 않는다.
5. 계산식은 해당 사건의 판단을 재현하기 위한 참고이며 현행 공통 공식으로 사용하지 않는다.
6. 동일 사건의 중복 웹 문서는 하나의 사례로 관리하고, MVP 범위 밖 원본은 RAG에 넣지 않는다.
7. 피해구제 합의권고 결과와 분쟁조정위원회의 조정 결정을 구분한다.

## 별도 표준답변 데이터

한국소비자원의 상담형 `품목별 피해구제사례` 12건은 조정 결정과 성격이 다르므로
`../kca_standard_answers/`에 분리했다. 해당 자료는 TV 수리 지연과 에어컨 부품 미보유 등
결정사례 조사 공백을 보완하지만, 실제 조정 결과로 인용하면 안 된다.

## 현재 범위 차이

프로젝트 역할 분담 기준은 냉장고·TV·청소기·에어컨 4종이지만, 저장소 상위 README에는 냉장고·세탁기·에어컨 3종이 기재되어 있다. 이 자료는 현재 역할 분담 기준으로 작성했으며, MVP 제품 범위는 팀 확인이 필요하다.
