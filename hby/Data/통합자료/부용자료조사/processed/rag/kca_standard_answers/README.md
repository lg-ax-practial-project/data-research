# 한국소비자원 품목별 피해구제사례 표준답변

한국소비자원 공식 상담형 Q&A에서 MVP 4개 제품과 관련된 고유 답변을 정제했다.
분쟁조정 결정사례와 섞지 않기 위해 별도 데이터셋으로 관리한다.

## 구성

- `answers.jsonl`: 표준답변 12건의 RAG 적재용 JSON Lines
- 개별 Markdown: 표준답변 12건의 질문·답변 원문, 쉬운 요약, 추가 질문, 증빙, 규칙 후보

## 핵심 표준답변

- `KCA-QA-2020-AC-USED-PARTS-001`: 중고에어컨의 품질보증 가능 여부
- `KCA-QA-2020-AC-FAULT-PARTS-001`: 소비자과실로 발생한 에어컨 고장 수리 불가능한 경우
- `KCA-QA-2020-AC-REPAIR-INSTALLMENT-001`: 에어컨 수리는 하지 않고 할부금만 독촉하는 경우
- `KCA-QA-2020-TV-DISCOUNT-EXCHANGE-001`: 할인 구매한 TV 교환시 차액을 추가 요구하는 경우
- `KCA-QA-2020-TV-REPAIR-DELAY-001`: 수리 지연되는 LCD TV 보상 방안 문의
- `KCA-QA-2020-TV-PURCHASE-DATE-001`: TV 구입일의 확인이 불가능한 경우 품질보증기간

## 사용 원칙

1. 표준답변을 실제 조정 결정이나 실제 이행 결과로 표현하지 않는다.
2. 질문 원문과 공식 답변 원문을 조사자의 쉬운 요약과 구분한다.
3. 2020년 답변의 기간·비율·법 조문은 현행 기준 대조 전까지 규칙으로 확정하지 않는다.
4. 개별 질문의 조건을 모든 소비자에게 일반화하지 않는다.
5. 공식 상세페이지 추적에는 `official_item_seq`를 사용하고, 목록 URL을 출처로 함께 보존한다.
