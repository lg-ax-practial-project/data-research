# 현행 가전제품 소비자분쟁해결기준 정리

기준일은 2026-09-28이며, 공정거래위원회고시 제2025-14호(2025-12-18 시행)와
한국소비자원이 제공하는 별표 Ⅱ·Ⅲ·Ⅳ 원문을 대조했다.

## 파일

- `rules.json`: Agent Tool 검토용 구조화 규칙 후보
- `standard_answer_crosscheck.md`: 2020년 표준답변과 현행 기준의 대조 결과

## 사용 원칙

1. `verified`인 항목도 실제 소비자에게 적용하기 전에 구입일, 품질보증기간, 제조일, 수리 횟수와 증빙을 확인한다.
2. 정액감가상각은 월할 계산하고, 제품별 내용연수는 사업자의 품질보증서와 별표 Ⅲ·Ⅳ의 우선순위를 확인한다.
3. 개별 사례와 표준답변의 결론을 일반 규칙으로 사용하지 않는다.
4. `not_confirmed`와 `separate_law_check`는 자동 판정에 사용하지 않는다.
5. 이 기준은 법원의 확정판결이 아니라 소비자와 사업자 사이의 분쟁 해결을 위한 합의·권고 기준이다.
