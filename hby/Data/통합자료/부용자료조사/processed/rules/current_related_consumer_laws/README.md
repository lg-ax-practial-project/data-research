# 가전 A/S 관련 현행 소비자법 규칙 후보

한국소비자원 표준답변 중 소비자분쟁해결기준만으로 판정할 수 없는 할부 항변권, 전자상거래 청약철회, 방문판매 청약철회 내용을 현행 법령과 대조한 결과다.

## 사용 범위

- `rules.json`: Agent가 확인할 조건을 구조화한 규칙 후보
- 원문 출처: `../../../raw/consumer_law/current_2026/sources.md`
- 현행 확인일: 2026-09-28

## 주의

- 법률 적용 여부는 계약 방식, 결제 방식, 가격, 통지 여부와 시점에 따라 달라진다.
- 규칙은 보상이나 철회 가능성을 확정하는 용도가 아니라, 추가 질문과 공식 근거 안내를 위한 후보 데이터다.
- 판매원의 시연과 소비자 사용의 책임 귀속은 구체적인 사실관계가 필요하므로 자동 판정하지 않는다.
