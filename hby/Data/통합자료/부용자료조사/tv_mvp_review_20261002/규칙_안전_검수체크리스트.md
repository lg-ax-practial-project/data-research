# TV 규칙·안전 검수 목록 — 승인 전 사용 제한

작성일: 2026-10-02. **현행 규칙 10개를 승인한 작업이 아니다.** R01~R03은 [공식 원문 1차 대조](규칙_원문대조_1차.md), R04~R06은 [점검·안전·출처 2차 대조](점검_안전_출처대조_2차.md)를 수행해 부분 검수로 기록했다. R07~R08은 [보증 예외·부품 보유 3차 대조](보증예외_부품보유_대조_3차.md)를 수행했다. R09~R10은 [환급·상담 절차 4차 대조](환급_상담절차_대조_4차.md)를 수행했다. 현재 10개 모두 부분 검수·미검수0개, 팀 승인과 실행/경계 테스트는 미완료다. 담당자는 대조 결과와 예외를 검토한다.

## 항목별 남길 승인 기록

- 검수자/역할, 검수일, 검수 범위
- 기관·문서명·정확한 URL/로컬 원문·조항/페이지
- 게시일·시행일·열람일, 과거 사례의 당시 기준과 차이
- 제품/구매 형태/보증 조건/기산일/예외
- 승인한 안내 또는 규칙, 아직 미확인인 조건
- 정상·경계·정보 부족·예외 입력과 기대 결과
- 상태: 미검수 / 부분 검수 / 승인 / 보류, 보류 사유와 후속 항목

검수자가 빈 항목을 가정으로 채우지 않는다. 정부 기준의 조건을 LG 정책 한 줄로 대체하지 않는다. 타 담당자의 이름이나 승인 완료일은 이번에 지정하지 않았다.

## 개인정보·공개 저장소 기준

현재 가상 질문/챗봇 응답은 실제 소비자의 영수증·주소·제조번호를 담지 않는다. 향후 실제 경험 자료는 별도 동의·비식별 검토가 필요하다.

- 원본 보존은 ‘공개 GitHub에 모두 업로드’와 다르다.
- 실제 영수증·결제내역·연락처·주소·제조번호·녹취·얼굴 이미지는 공개 저장소에 올리지 않는다.
- 실제 인터뷰 메모는 동의 범위로 관리하고 공개용 요약과 분리한다.
- 공식 웹 원문 재배포는 기관의 이용 조건/라이선스를 확인한다. 미확인 파일은 링크·메타데이터·필요 최소 요약을 우선하고 공개 푸시 전에 검토한다.

## 최소 테스트 예시 — 모두 가상, 검수 결과 아님

- 보증: 구매일 추정, 증빙 있음/전혀 없음, 제조일 미상, 제품/부품 조건 차이.
- 반복: 방문 2회지만 실제 수리 1회, 두 번 실제 수리 후 재발, 같은 증상이나 진단 원인 불명, 보증 미확인.
- 지연: 의뢰일 불명, 날짜와 ‘40일’ 진술 불일치, 부품 지연 구두 안내만 있음, 수리 불가 서면 통보.
- 자가 점검: 리모컨 종류 불명, 모델 불명, 메뉴가 안 보임, 사용자가 결과를 모름으로 입력.
- 근거: 공식 도메인인데 다른 제품 페이지, 맞는 제품이나 과거 버전, 링크 접근 불가.

법적 결과·진단 정답은 해당 항목 승인 후에만 정한다. 위 예시는 테스트 설계 후보다.
