# LG TV MVP — 팀 검토용 기능 선택안과 검수 목록

작성일: 2026-10-02. 상태: **제안·검수 준비 완료, 팀 승인과 규칙 검수는 미완료**.

기능 선택안 작성 후 R01~R03 보증·반복 하자·수리 지연, R04~R06 모델/리모컨·안전·출처, R07~R08 보증 예외·부품 보유를 공식 원문과 대조했다. 10개 모두 부분 검수, 미검수는 0개이며 팀 승인과 실행/경계 테스트는 미완료다. 개발, 팀원 메시지 발송, 인터뷰, Git 커밋/푸시는 하지 않았다. 기존 원본과 rules.json은 수정하지 않았다.

- [팀검토_인계요약.md](팀검토_인계요약.md): 현재 확보 결과·제한·팀이 결정할 사항을 한 번에 확인.

- processed/review_items.json: 10개 검수 항목의 추적 목록. 담당자는 역할로만 제안했으며 검수자 이름·승인일·확정 결과는 모두 비어 있다.

## 근거와 완료 범위

근거: [기존 서비스 1차 비교](../tv_user_research_20261002/서비스비교_1차종합.md). 6개 가상 시나리오·8턴 제공 응답이며 실제 고객 인터뷰는 0명이다. 입력/세션 증거 및 기존 시스템 전체 기능 비교는 미완료다.

기존 규칙 참고: [규칙 후보 폴더](../processed/rules/kca_current_appliance_rules/README.md). 이전 검증 상태를 이번 기능 사용 승인으로 승계하지 않는다.

신규 대조: [규칙_원문대조_1차.md](규칙_원문대조_1차.md). raw/에 공식 별표 PDF·본문 이미지와 웹 본문 추출본을 보존했다. 시행령의 제조/수입통관일+3개월 근거도 확인했으나 기존 규칙 파일은 변경하지 않았다.

## 다음 행동

최근 결과: [점검_안전_출처대조_2차.md](점검_안전_출처대조_2차.md). raw/r456_*.md에 공식 LG 본문 4개, processed/r456_evaluation_candidates.json에 미실행 가상 평가 후보 8개를 보존했다. 3차 결과: [보증 예외·부품 보유 대조](보증예외_부품보유_대조_3차.md). R07~R08까지 대조했으며 [환급·상담 절차 4차 대조](환급_상담절차_대조_4차.md)로 R09~R10도 다뤘다. 원문 대조 목록은 전부 부분 검수 상태이며, 규칙 승인·운영 안전성·법적 적합성·실행 테스트는 완료되지 않았다. 모델별 매뉴얼과 안전 조치 전체를 승인한 것은 아니다.

1. 팀이 기능선택안의 결정 항목 4개를 검토한다.
2. 공식 기준·LG 정책 담당자가 관련 항목의 출처·버전·조건·예외를 확인한다.
3. 승인된 좁은 범위로 기능/평가 담당자가 설계와 테스트 범위를 정한다. 승인되지 않은 항목은 확인 필요/전문 점검 연결로 남긴다.
4. 실제 경험자 모집이 되면 기존 인터뷰 진행지로 고객 문제를 검증한다. 모집 실패는 인터뷰 0명으로 기록하고 효과를 주장하지 않는다.

이번 문서 준비 시간과 외부 검수·팀 결정·개발 완료 시간은 다르다. 후자는 담당자 일정이 없으므로 확정할 수 없다.
