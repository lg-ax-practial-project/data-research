공식 검색 → 개별 원문 본문 확인 → URL 단위 중복 구분 → 자료 유형 구분 → 첫 고장 이력 확인 → 원문 발췌와 요약 → 기능 가설 및 검증 필요 사항 분리.

발췌 8개가 각 저장 본문에 실제 존재하는지 검증했다. 자료 ID·URL·JSON 구조를 확인했다. 원문이 맞다는 점과 현행 법령에 적용 가능한지는 별개의 검증이다.
