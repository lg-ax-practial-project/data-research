# TV 첫 고장 경험 확인 질문 — 인터뷰 초안

이 문서는 질문 초안이며 인터뷰를 실시하거나 응답을 수집한 결과가 아니다. 동의를 받고 익명으로 기록한다. 먼저 실제 첫 고장·첫 증상 경험인지 확인한다.

1. TV 브랜드·모델과 대략적인 구입·배송 시점을 기억하나요?
2. 이번 증상이 이 TV에서 처음인가요? 이전 고장·A/S 접수·실제 수리 이력이 있나요?
3. 처음 어떤 증상이 나타났고, 언제 알게 됐나요?
4. 고장이라고 생각한 직후 가장 먼저 무엇을 했나요?
5. 처음 찾은 정보와 실제 검색어는 무엇이었나요?
6. 공식 안내에서 따라 하기 어렵거나 찾지 못한 부분이 있었나요? 화면이나 행동을 구체적으로 설명해 주세요.
7. TV 자체 문제인지 셋톱박스·케이블 문제인지 구분할 수 있었나요?
8. 무상수리 여부나 비용을 확인할 때 어떤 정보가 필요했고 무엇을 확인하지 못했나요?
9. A/S를 신청했다면 준비·입력·설명 과정에서 막힌 점이 있었나요? 신청하지 않았다면 이유는 무엇인가요?
10. 증상 사진·발생일·접수·점검 결과를 보관했나요? 이후 다시 설명해야 하는 상황이 있었나요?

## 기록 항목

익명 ID / 첫 고장 명시 여부 / 증상 / 실제 행동 순서 / 찾은 정보 / 막힌 단계 / 사용자가 말한 어려움 / 직접 인용 / 조사자의 해석 / 기능 제안 / 확인 필요 사항.

질문자가 “보증이 어렵죠?”처럼 불편함을 유도하지 않는다. 응답이 없으면 미확인으로 남긴다. 몇 명의 인터뷰 결과를 전체 LG 고객 비율로 일반화하지 않는다.
