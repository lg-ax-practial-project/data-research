# 1차 발견과 프로젝트 활용

## 핵심 발견

현 단계에서 근거가 있는 것은 **상황별로 확인해야 할 정보가 다르다**는 점이다. 첫 고장 고객이 가장 많이 겪는 어려움, LG 기존 서비스의 기능 공백, Agent 효과는 아직 입증하지 않았다.

## 1. 화면이 안 나와도 확인 경로가 다르다

**공식 원문에서 확인한 사실:** LG 가이드는 음량 표시 유무, 신호 없음 표시, 셋톱박스·케이블 사용 여부를 구분해 점검을 안내한다. 일부 안내에서는 전문 점검을 권장한다.
[LG 화면·소리 점검](https://www.lge.co.kr/support/solutions-1777897), [OLED 화면 안내](https://www.lge.co.kr/support/solutions-20152183148933).

**해석·인사이트 가설:** 사용자가 “TV가 고장 났다”라고 입력한 것만으로 TV 자체 고장이나 부품 교체가 필요하다고 정하면 안 된다.

**Agent 기능 제안:** 화면/소리/전원 상태 → 음량 표시 → 시청 방식 → 외부기기 여부를 추가 질문하고 공식 가이드와 전문 점검 경로를 연결한다.

**아직 검증하지 못한 것:** 이 분기를 실제 사용자가 어려워하는 비율, 자가 점검으로 해결되는 비율, 불필요한 출장 감소 효과.

## 2. 모델·webOS를 모르면 메뉴 안내가 어긋날 수 있다

**확인한 사실:** 신호 없음·음향 가이드는 제품 연도와 webOS에 따라 서로 다른 메뉴 경로를 안내한다. 실제 구매연도와 webOS 버전은 다를 수 있다고 명시한다.
[신호 없음](https://www.lge.co.kr/support/solutions-1777960), [음향 자가진단](https://www.lge.co.kr/support/solutions-20150903914041).

**해석 가설:** “설정에서 자가진단을 누르세요”라는 단일 경로 안내로는 일부 모델에 맞지 않을 수 있다.

**Agent 기능 제안:** 모델·제품 종류·버전을 확인하고, 불명확할 때는 버전을 추측하지 말고 공식 확인 경로를 보여준다.

**추가 검증:** 서로 다른 TV 모델의 사용자 또는 테스트 환경에서 메뉴 찾기를 수행해 어떤 단계에서 막히는지 확인한다.

## 3. 보증기간 안이라는 정보만으로 무료 수리를 확정할 수 없다

**확인한 사실:** LG 정책은 구입 증빙·배송일·제품과 핵심부품 보증·사용 조건·외부기기 문제·직구 등 예외를 함께 안내한다. 제품 고장이 아닌 고객 요청 점검은 보증기간 안이라도 유상일 수 있다고 적혀 있다.
[LG 요금/보증](https://www.lge.co.kr/support/rates-warranty-guide).

**기존 자료에서 발견한 질문:** 영수증을 보관하지 않아 구입 시점·보증기간을 다투는 TV 표준답변이 있다. 실제 상담 원장이나 첫 고장 표본이 아니라 상담형 표준답변이다. [소비자원 공식 목록](https://www.kca.go.kr/odr/cm/in/exmplPgItem.do?brdId=00000006&dataStts=Y&multiItmSeq=8). 기존 항목 ID는 별도 재활용 문서 참조.

**기능 제안:** 증빙 유무·구입/배송 시점·국내/직구·사용 환경·진단 여부를 조건 카드로 정리한다.

**주의:** 기간·부품·예외별 검수가 끝나기 전 무상수리 가능 여부나 예상 총액을 확정하지 않는다.

## 4. 간헐적 증상에서는 기록의 시점과 내용이 중요하다

**확인한 사례:** 화면 꺼짐 TV 사건은 소비자의 반복 하자 주장과 보증기간 내 수리 사실을 구분했다. 뒤늦게 촬영한 영상이나 임의 메모만으로 보증기간 내 하자·수리를 인정하기 어렵다는 판단이 있다.
[소비자원 조정 원문](https://www.kca.go.kr/odr/bj/br/osBjDecisionExamDetW.do?brdId=00000007&dataStts=Y&seq=1003477844).

설치 직후 패널 이상 사건에서는 증상 사진과 사업자의 책임 관련 증빙을 비교해 판단했다.
[소비자원 조정 원문](https://www.kca.go.kr/odr/bj/br/osBjDecisionExamDetW.do?brdId=00000007&dataStts=Y&seq=1003382632).

**해석 가설:** 첫 증상부터 날짜·사진·접수·점검·수리를 구분해서 보관하는 기능이 이후 상담 준비에 도움이 될 수 있다.

**기능 제안:** 사용자 입력 기반 타임라인과 증빙 체크리스트. 접수했다는 기록을 수리 완료 횟수로 계산하지 않는다. 사진·영상의 촬영일과 주장하는 고장 발생일도 구분한다.

**한계:** 분쟁에 도달한 선별 사례에서 도출한 가설이다. 모든 첫 고장 고객에게 동일 어려움이 있다고 일반화하거나 기록만 있으면 보상된다고 약속하지 않는다.

## 5. 기존 LG 서비스가 이미 제공하는 기능도 있다

점검 가이드는 상담·출장 예약 링크를 제공한다. 예약 안내에는 모델명을 모르면 제품군으로 예약하는 경로도 존재한다.
[LG 출장 예약](https://www.lge.co.kr/support/service-engineer-reservation).

따라서 “기존 LG에 자가 점검이나 예약 안내가 없다”를 차별점으로 내세울 수 없다. 현재 확인은 정적 페이지 확인이며, 기존 챗봇과 동일 시나리오 대화 테스트는 미수행이다.

**차별화 검증 후보:** 점검 결과와 보증 조건 및 증빙을 이어서 보관·재사용하고 상담 준비 문서에 연결하는 과정. 실제 기존 서비스가 이를 어느 정도 지원하는지 비교한 후에 차별점으로 채택한다.

## 분석 결과의 사용 한계

자료별 주제는 목적에 맞춰 선별한 목록이다. 제목이나 자료 수를 세어 “주요 문의 순위”를 만들지 않는다. 첫 고장 고객의 실제 문제를 입증하려면 기존 전체 TV 표준답변 선별과 실제 첫 고장 경험 인터뷰를 보완해야 한다.
