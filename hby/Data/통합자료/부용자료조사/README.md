- 피해구제 PDF 중 동일한 2022년 연보 2개는 중복으로 표시하고 한 문서로 계산했다.

## 주의

- 개별 사례의 결론은 모든 고객에게 적용되는 일반 규칙이 아니다.
- 과거 사례에 적용된 기준은 현행 기준과 대조해야 한다.
- 실제 조정 결정의 이행 여부가 원문에 없으면 `원문 미기재`로 기록했다.
- 품목별 피해구제 표준답변은 조정 결정이나 실제 이행 결과가 아니므로 결정사례와 별도 데이터셋으로 관리한다.
- 사례에서 발견한 계산식은 공식 기준 담당자의 검증 전까지 Tool 규칙으로 확정하지 않는다.
- 저장소 공통 README의 MVP 제품 범위와 현재 역할 분담의 제품 범위가 달라 팀 확인이 필요하다.
