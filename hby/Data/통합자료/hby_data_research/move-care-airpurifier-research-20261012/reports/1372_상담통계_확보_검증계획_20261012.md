# 1372 상담 통계 확보·검증 계획

2026-10-12. **통계 API는 LG 약관·FAQ 검색 RAG 구축의 필수 조건이 아니다.** 초안의 상담 비율을 그대로 인용하려면 원자료와 집계 조건이 필요하며, 이 API는 그 자료를 직접 확보할 수 있는 후보 경로다. 사용자는 활용신청을 하지 않은 상태다. 이번에는 신청·인증키 요청·API 데이터 호출을 하지 않았다.

## 신청보다 먼저 확인할 자료

팀에 이미 있는 **원 추출 파일, 추출일, 월별 범위, 품목/사유 코드표, 집계 코드 또는 집계표**가 우선이다. 그것으로 재현되면 사용자가 별도 API를 신청할 필요는 없다. 현재 확인한 khh/minsong 브랜치에는 해당 원 추출본이 없었다. 팀원 PC나 다른 저장 위치까지 부재를 확인한 것은 아니다. 문의를 발송하지 않았다.

원자료를 확보하지 못하고 초안 비율을 유지하려면, 공공데이터포털 위 공식 페이지의 ‘활용신청’을 통해 이용 권한을 얻는 방법을 선택할 수 있다. **현재 신청을 진행하지 않아도 정책 자료 정제 준비는 계속할 수 있다.** 사용자가 선택하면 계정 화면을 기준으로 신청을 안내한다. 인증키는 채팅·README·Git에 넣지 않고 별도 로컬 설정에서 사용한다.

## 실제 원자료 확보 후 할 순서 — 아직 실행하지 않음

1. 원 추출본/최종 집계의 기간·추출일을 고정한다. API로 재수집하면 먼저 한 월의 최소 응답으로 코드·구조·건 단위를 확인한다.
2. 명세와 실제 응답이 일치하는지, 성공코드·월·전체 건수·페이지 누락을 확인한다. 문서화된 품목 요청 필터는 없으므로 임의 파라미터를 만들지 않는다.
3. 모든 필요한 월의 원 응답과 페이지별 해시·수집 기록을 보존한다. 인증키가 붙은 URL이나 로그는 보존 자료에 노출하지 않는다.
4. 공식 코드표로 품목·사유·처리결과를 매핑한다. 식별자 없이 같은 속성의 행이라는 이유만으로 상담 건을 중복 삭제하지 않는다.
5. 집계별 분자·분모·제외 건수·결측 처리·반올림 규칙을 기록한다. 두 기간 비교는 데이터 완결성도 확인한다.
6. 초안과 차이를 보고한다. 수치만 맞추려고 기간·분모를 바꾸지 않는다. 정책 RAG 색인에는 상담 원자료와 평가 정답을 넣지 않는다.

API 이용 승인만으로 통계 검증이 끝나지 않는다. 현재 초안 비율은 최종 인용 보류이며, 제출 시점까지 검산하지 못하면 확인된 소비자원 실태조사의 모집단·기간을 표시한 근거로 설명을 구성해야 한다.
