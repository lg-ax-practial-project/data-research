# 인사이트 → CX → Agent 연결 수정안

2026-10-12 조사에 근거한 기획 제안이다. 팀 확정 기획서나 구현 명세를 대체하지 않는다.

## 1. 현재 근거로 사용할 수 있는 인사이트

> 한국소비자원에 2022년 1월부터 2025년 6월까지 접수된 가전 구독·렌탈 피해구제 2,624건 중 계약 관련 불만은 55.1%였다. 별도의 이용 경험자 500명 설문에서는 31.4%가 중도해지 위약금이 없다고 인지했고, 27.8%는 위약금 외 추가 비용이 발생할 수 있다는 사실을 몰랐다. 따라서 구독 고객이 자신의 계약에 따른 해지 비용과 조건을 함께 확인하도록 돕는 기능을 검토할 근거가 있다.

출처: [KCA 실태조사 원본](../raw/official-pdf/한국소비자원_가전구독렌탈_실태조사_202512.pdf), 물리 14·19·22쪽. 공기청정기·LG 고객만의 통계는 아니며, 이사가 주요 원인이라는 뜻도 아니다. 구매 대비 렌탈 3.3배, 40~50대 54.5%, 합의불성립 17.5%는 원자료 검산 전까지 확정 문장에 넣지 않는다.

공기청정기는 공식 구독 운영과 방문 관리형 상품이 확인되어 검토할 수 있다. 이사는 고시에 정기관리 불가·해외 이주 등 별도 조건이 존재하는 **검증 가능한 시나리오로 선택**한 것이며, 이사 고객 규모나 발생 빈도에 관한 통계적 결론이 아니다.

## 2. 가상 페르소나

| 항목 | 제안 | 근거 수준 |
| --- | --- | --- |
| 이름·나이·가구 | 박지현, 43세, 맞벌이·자녀 2명 | 시나리오 가정. 연령 통계 검증 전 ‘데이터로 정함’으로 표시하지 않음 |
| 제품 | LG 360˚ 공기청정기 제품 구독 | 공식 상품 운영 확인. 모델은 별도 결정 |
| 관리 형태 | 방문 관리형, 3개월 또는 6개월 주기 중 계약에 맞게 선택 | 공식 서비스 선택지 확인. 구체 주기는 Mock 계약에서 명시 |
| 계약 | 총 계약기간·의무사용기간 각각 명시, 14개월 사용 | 고객 계약을 조회한 사실 아님. 총 5년 선택지가 5년 의무사용을 증명하지 않음 |
| 상황 | 다음 달 이사, 새 집에서 관리 가능한지 불확실 | 시나리오 가정. 경기도 외곽·강원 산간이라는 지역명만으로 관리 불가로 확정하지 않음 |
| 고민 | “계속 관리받을 수 있나? 해지하면 위약금 외에 무엇을 내나?” | 공식 비용 항목과 면제 규정에서 도출한 설계 질문 |
| 시간 제약·현재 행동 | 퇴근 후 짧게 처리하고 싶고 여러 안내를 찾는 데 부담 | 가설. 실제 이용자 조사 필요. 합의불성립 비율로 통화 대기/이해 실패를 입증하지 않음 |

‘14개월 사용’을 2026-10 시점의 상황으로 설정하면 계약 성립 시점은 대략 2025-08 전후다. 실제 날짜는 가상 계약으로 정하고, 2026년 안내가 당시 계약에 적용된다는 가정은 별도 확인한다. 2026년 출시 모델과 14개월 사용을 함께 설정하는 모순도 피한다.

## 3. CX 문제 정의 문장

> 방문 관리형 LG 공기청정기를 구독 중인 고객이 이사를 앞두고 이용을 계속할지 해지할지 결정할 때, 자신의 계약·새 주소의 관리 가능 여부·해지 비용 항목·면제 또는 감면 조건을 한 번에 확인하기 어렵다는 문제를 해결하고자 한다. 고객의 조건에 맞는 공식 근거와 미확인 사항을 함께 제시하고, 고객이 선택한 후 필요한 후속 처리를 돕는 흐름을 검증한다.

이는 검증할 CX 가설이다. 정보 부족 때문에 실제로 분쟁이 발생했다는 인과나 기존 LG 채널이 모두 실패한다는 사실을 단정하지 않는다. LG 보이는 ARS에서 이미 주소 변경·방문 요청을 제공하므로 As-Is는 ‘주소 변경 수단이 없다’가 아니다.

## 4. 근거와 설계 연결

| 근거 | 제안 기능 | 확인해야 할 성과 |
| --- | --- | --- |
| KCA 위약금 없음 인지 31.4%, 추가비용 미인지 27.8% | 위약금·회수비·미납 등 항목과 출처 분리 안내 | 고객이 총 정산 항목과 미확인 항목을 구분하는가 |
| LG 35,000/39,000원 안내 차이, 계약서 금액 적용 | 계약 성립일·유형·모델·금액 및 약관 버전 확인 | 다른 시점의 규정을 섞지 않는가 |
| LG 요금제별 방문 관리/자가관리 차이 | 관리 유형 확인 후 주소별 관리 확인 분기 | 자가관리를 방문관리로 오판하지 않는가 |
| 고시의 이사·해외 이주 조항 | 사유와 증빙 확인, 적용 가능 근거 검색 | 면제 후보와 확정 처리를 구분하는가 |
| LG와 고시의 계산 기준 차이 | 두 근거의 성격·산정 기준을 구분, 필요한 경우 상담 확인 | 단일 근거를 임의 우선하지 않는가 |
| KCA 총 비용 비교 문제 인식 67.2% | 유지·해지의 같은 기간 총비용 및 일회성 비용 구분 | 비교 기간·포함 항목·불확실성이 표시되는가 |
| 주소 변경·방문 요청의 공식 운영 채널 존재 | 사용자 선택 후 Mock 주소 변경/회수 요청 흐름 | 승인 내용과 처리 결과가 구분되는가 |

모든 기능에 숫자 하나를 억지로 연결할 필요는 없다. 통계는 문제 규모·인식의 근거이고, 약관은 조건·예외의 근거이며, 승인 절차·Mock 예약·평가 수량은 설계 결정이다. 출처와 결정 이유가 추적되도록 한다.

## 5. 조사 결과를 반영한 처리 순서 제안

상황 확인 → Mock 계약 조회(제품/관리형태/계약 버전) → Mock 관리 가능 여부 확인(가능·불가·확인 필요) → 공식 규정과 예외 검색 → 적용 조건이 확인된 비용만 계산 Tool에 전달 → 유지/해지 비교 → 고객의 구체적 선택과 승인 → Mock 후속 처리.

관리지역 미확인, 약관 버전 부재, 회수비 충돌, 해외 이주 증빙 누락은 ‘금액 추정으로 진행’하지 않고 필요한 항목을 요청하거나 근거를 묶어 상담 확인 대상으로 분기한다. ‘관리 불가’ 가상 결과를 LG의 실제 판정으로 표현하지 않는다.

초안의 `search_terms`와 기존 기획 `search_contract_terms` 명칭 차이, 주소 변경/회수/상담 접수 Tool의 범위는 팀 협의 사항이다. 이 문서는 함수명·입출력 스키마·공통 API를 변경하지 않는다.

비용 비교는 지금부터 같은 종료 시점까지를 기준으로 하되 일회성 해지 정산, 앞으로의 구독료, 유지 시 이동·관리 비용, 포함하지 못한 항목을 분리하는 방식으로 합의한다. 남은 구독료를 위약금에 중복 더하지 않도록 계산 담당자와 확인한다.
