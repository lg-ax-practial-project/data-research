## 이번 작업 — 공식 자료 추가 수집7차 / 2026-10-13

**자료조사는 아직 완료되지 않았다.** 공개 경로를 추가 확인해2022년 개정 공지의 렌탈 약관 전문과2026-08-28 배포용 공식 카탈로그PDF를 확보했다. FAQ·서비스 안내·공기청정기 가이드3개도 재수집했다. [추가 수집 결과](move-care-airpurifier-research-20261012/reports/추가수집_20261013_07.md).

공식 출처는[32개 목록](move-care-airpurifier-research-20261012/metadata/source_manifest_20261013_07.json)으로 갱신했다. 과거 약관을 현행으로 사용하지 않으며, 회수비35,000원/39,000원 적용 경계·실제 면제 처리·개별 계약 약관은 여전히 미확인이다. [남은 조사](move-care-airpurifier-research-20261012/metadata/research_open_items_07.json), [반영 검증](move-care-airpurifier-research-20261012/metadata/additional_verification_07.json). 기존30개 목록·정제27묶음·원본은 보존했다.

## 이전 작업 — 공식 근거 정제 / 2026-10-13

공식 출처30개를 용도별로 분류하고, 12개 출처에서 **근거27묶음**을 정제했다. 회수비의 날짜·계약서 확인, 위약금 예외, 관리 주기 차이를 원문과 함께 보존했다. [정제 결과 보고서](move-care-airpurifier-research-20261012/reports/RAG_자료정제_결과_20261013.md), [근거 묶음 검토본](move-care-airpurifier-research-20261012/processed/curation_20261013/근거묶음_검토본.md).

표2개를 원문 구조에 맞게 정리하고, 상충하거나 불명확한 문구2개는 검색 후보에서 분리했다. 기존20개 질문에는 필요한 근거/처리 경로를 연결했다. **검색·Agent 평가는 아직 실행하지 않았다.** [자료 읽는 방법](move-care-airpurifier-research-20261012/processed/curation_20261013/README.md), [검증 기록](move-care-airpurifier-research-20261012/metadata/curation_validation_20261013.json).

원문은2026-10-12 보존 수집본이며 오늘 새 정책을 확인한 것은 아니다. 실제 계약 적용·통계 검증은 남아 있다. 임베딩·검색 색인·공통 API 변경·커밋·Push는 하지 않았다.1372API 신청 없이도 이 정제 단계는 진행할 수 있다.
