# LG Move Care — 기획 요약과 데이터 조사 패키지
조사 기준일: 2026-10-12

## 1. 한 문장으로
이사하는 LG 워시타워 구독 고객이 자신의 계약과 설치 조건을 확인하고,
해지와 이전의 비용을 비교한 뒤, 고객 동의를 거쳐 **가상 이전설치 예약까지** 마치는 서비스다.

## 2. 원 기획안 요약
- 범위: 워시타워 1종, 단일 Agent, React 웹서비스.
- 흐름: 계약 조회 → 관련 규정 검색 → 해지비 계산 → 이전 견적/설치 확인 → 비교 → 최종 동의 → 데모 예약.
- 실제 자료: LG 공개 FAQ·서비스/설치 안내. 고객별 계약과 예약 시스템은 Mock.
- 핵심 도구 5개: get_customer_contract, search_contract_terms, calculate_termination_cost,
  get_relocation_quote, manage_relocation_booking.
- 기술은 원안 기준 React/TypeScript/Vite + FastAPI + LangChain + ChromaDB + FastMCP + SQLite.
- 데모는 실제 LG 시스템에 접속하거나 실제 예약을 생성하지 않는다.
- 원안 일정: 2026-10-16 금요일 오전 11시 제출.
- 원안 평가: 정상15, 정보부족5, 예외5, 위험5의 총30사례. 정확도와 완료율 수치는 목표이지 실측 결과가 아니다.
원안 출처: 사용자가 첨부한 「붙여넣은 텍스트(1).txt」.

## 3. 수집 범위와 정직한 구분
- 외부 출처/데이터 경로 27개: 일부는 전문, 일부는 메타데이터, 일부는 접근 실패한 원문 경로다.
- 공개 관측/안내/메타 수치 70행을 직접 표로 정리했다.
- 공개 데이터의 필드 57개를 정리했다. API 한국어 항목명이 실제 JSON 키를 보장하지 않는다.
- 공개 안내 요약 규칙 22개를 JSONL/CSV로 만들었다. 서명된 약관 전문이나 법률 판정표가 아니다.
- 제안 DB 필드 95개, 분석 설계 14개, 테스트 30개,
  인터뷰 질문 15개를 작성했다. 이들은 새 설계안이지 수집된 고객 관측치가 아니다.
- 합성 계약 5건은 테스트 예시다. 실제 LG 요금제/개인고객 데이터가 아니다.
- 공공데이터포털의 피해구제 CSV **12834행 전체는 다운로드하지 못했다**.
  행 수는 포털 표시값이며, 품목/청구이유별 실제 분석은 실행하지 않았다.
- 원문 파일과 공식 조사 PDF 일부는 접근/다운로드에 실패했다. KCA 가전 구독 조사 수치는
  파이낸셜뉴스·한겨레·농민신문의 조사 보도를 교차 확인한 2차 출처 값으로 표시했다.
- 출처별로 수집 성공 범위/미확보 상태를 source_catalog.csv에 표시했다.

## 4. 핵심 사실과 해석 한계
### 계약 문제
KCA 조사 보도: 2022-01~2025-06 가전 구독 피해구제 2624건,
계약1446건(55.1%), 품질/AS908건(34.6%). 별도 경험자 설문500명 중
위약금 수준 미인지157명(31.4%). [S10, S11]
정수기1528건(58.2%)이며, 냉장고/세탁기/에어컨 등 대형가전 묶음은
2022년16, 2023년19, 2024년39건으로 보도됐다. [S12]
→ 계약 정보 이해의 필요성은 뒷받침하지만, 워시타워 이사가 해지의 최대 원인이라는 증거는 아니다.

### 비용과 혜택
LG FAQ의 워시타워 회수비는 2026-03-24 기준111000원이고 실제 계약 기재액을 따른다. [S01]
위약금은 할인 전 기본 월요금 기준으로 확인한다. 사용기간별 비율은 개별 계약/경계조건과 대조한다.
워시타워 철거·재설치는 계약기간 중1회 무상 안내가 있으나 운송은 별도이며 환경별 비용이 생길 수 있다. [S02]
LX판토스는 10km 미만 운송 기본비40000원을 공개한다. 그 이상 구간의 단위 거리 산정 방식,
부자재/장비/혜택 적용 여부가 미확인이라 계산기를 임의로 확정하지 않았다. [S07]
→ 원안 운송80000원은 그대로 Mock 예시다. 공개 요율로 바꾸려면 견적 조건 확인이 선행되어야 한다.

### 계약기간과 소유권
의무사용기간과 총 계약기간을 분리해야 한다.
LG는 해당3년 구독상품에 대해 만기 인수(일반판매가10%) 또는 반납 선택을 안내한다. [S03]
→ 36개월을 쓰면 모든 제품을 무료로 소유한다고 자동 판단하지 않는다.

### 설치
W2421KKAM은 세탁24/건조21kg, 본체700×1890×830mm, 문 개방 깊이1410mm, 총무게162kg이다. [S05]
제품치수는 설치가능 최소공간과 다르다. 급배수·전원·문폭·동선·장애물은 별도로 확인한다. [S04]

### 이사 배경
2025년 이동자611.8만명, 이동률12.0%, 20대24.3%, 30대20.4%다. [S22]
2024년 주거실태조사의 현 주택 거주기간2년 이내 비율은30.3%다. [S24]
→ 각각 사람 단위 이동통계와 가구 단위 단면 거주기간 지표다.
서로 곱해서 LG 구독 이사 고객 수를 산출하거나 30.3%를 연간 이사율이라고 하면 안 된다.

### 차별화
LG는 이미 이전설치 예상비용 조회 및 AI Chat 안내를 제공한다. [S06]
→ 제안 차별점은 'AI 견적 최초'가 아니라 **개별 계약에 맞는 근거 있는 선택지 비교와 확인된 예약 흐름**이다.

## 5. 파일 사용 순서
1. LG_Move_Care_기획요약_데이터팩.xlsx의 00_요약과 01_출처목록을 먼저 읽는다.
2. 02_공개수치에서 발표 근거를 골라 쓰되 기간·모집단·출처등급을 함께 표시한다.
3. 원자료 분석은 S13/S14 CSV를 실제 다운로드한 뒤 public_dataset_columns.csv와 대조한다.
4. 02_rules의 JSONL은 RAG 시작용이다. 실제 계약 버전 원문, 조항 위치와 정식 적용 범위로 보강한다.
5. 03_design은 데이터 설계 제안, 04_evaluation은 미실행 테스트, 05_examples는 합성 사례다.

## 6. 원자료 확보 후 가능한 분석
세탁기 관련 품목을 실제 고유값에서 확인 → 구매/렌탈 혼합 여부 점검 →
청구이유·처리결과·연령 분포를 집계한다.
상담건수와 피해구제건수는 별개 단계이며, 전 국민/가입자 수를 분모로 한 발생률이 아니다.
2025년 상반기를 2024년 전체와 바로 비교하지 않는다.
같은 코드값이 없는 KOSIS와 소비자원 자료를 개인 단위로 결합하지 않는다.

## 7. 먼저 채울 빈칸
가장 중요한 미확보 자료는 고객의 실제 적용 약관, 계약 요금/회수비, 혜택 사용이력,
확정 설치 가능 여부, 제공자 견적과 실시간 일정이다.
또한 이사 고객의 실제 불편과 해지 사유는 사용자 인터뷰/동의받은 운영 로그로 검증해야 한다.
공공 통계가 이 빈칸을 대신하지 않는다.

## 8. 최소 구현 제안
워시타워 모델1개 + 적용규정이 명시된 가상 계약1개 + 정상 이전예약1개를 먼저 완성한다.
그다음 정보누락/혜택소진/설치불가/중복예약을 막는다.
고객이 해지를 택한 경로는 '실제 해지 완료'가 아니라 정산/상담 필요 상태로 구분한다.
비용 비교는 일회성 지출과 동일기간 미래 현금흐름, 만기 잔존가치·인수 조건을 구분한다.
