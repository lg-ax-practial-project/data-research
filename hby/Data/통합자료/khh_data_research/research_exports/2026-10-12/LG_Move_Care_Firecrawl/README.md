주제: 워시타워·LG 가전 구독의 해지/구매 비교, 이사, 이전설치

## 먼저 볼 파일

실제 댓글은 `03_댓글요약`, 경험담은 `02_게시글요약`, 근거를 기능에 연결한 제안은 `04_기획반영`에 있습니다.

- 실제로 읽힌 고유 댓글·답글 60행: 유튜브 14, 클리앙 26, 티스토리 6, X 3, 디시인사이드 11.
- 이 중 질문·경험·선택 기준을 다루는 42행을 분석 포함으로 분류했습니다. 짧은 반응, 안내 답글, 비관련 논쟁 등 18행은 제외했습니다.
- 42는 불만 건수도, 구독 고객 수도, 독립적인 사람 수도 아닙니다. 긍정적 의견과 질문도 포함합니다.

## 유튜브 수집의 정확한 범위
S004: https://www.youtube.com/watch?v=wLyPfiOg4Cs  
공식 안내 영상의 화면에는 댓글 30개가 표시됐지만, 실제 본문을 읽은 것은 최상위 댓글 11개와 답글 3개, 합계 14개입니다.
Firecrawl의 일반 YouTube 읽기는 설명·자막만 반환하므로, 별도 브라우저에서 댓글 DOM을 확인했습니다.
동일 답글이 중복 노출된 경우 `lc` 댓글 ID로 중복을 제거했습니다. 답글은 `lc`에서 첫 점 앞 부분을 부모 ID로 보았습니다.
답글 작성자가 공식 채널인지 확인되지 않아 `안내 답글·작성자 미검증`으로 저장했고, 고객 의견 분석에서 제외했습니다.
정렬 방식은 확인되지 않았습니다. 이후 추가 수집 요청은 시간초과되어 전체 댓글 수집 완료로 표시하지 않았습니다.

S013: https://www.youtube.com/watch?v=OewkQmHQfHM  
영상 메타데이터만 확보했습니다. 댓글 접근은 시간초과/후속 요청 차단으로 0개입니다.
검색 결과에 나타난 댓글 추정 문장을 실제 댓글 데이터에 넣지 않았습니다.
네이버 블로그에 표시된 댓글 개수도 실제 본문을 받지 못한 경우 수집 댓글로 계산하지 않았습니다.

## 파일 구성과 열 의미
- `sources.csv` / `sources.jsonl`: 원문 URL, 게시일 표기, 자료 유형, 수집 방식, 확인 범위, 주의사항.
- `post_summaries.csv` / `.jsonl`: 게시글별 비식별 요약, 경험 단계, 구독 여부, 포함/제외.
- `comments.csv` / `.jsonl`: 댓글별 비식별 요약, 주제코드, 작성 역할, 날짜, 플랫폼 ID, 원문 URL, 부모 기록.
- `short_quotes.csv` / `.jsonl`: 매우 짧은 원문 인용 2개.
- `theme_codebook.csv` / `.jsonl`: 주제 정의, 근거 ID, 관찰과 구분된 기능 제안, 평가 질문.
- `collection_log.csv` / `.jsonl`: 주요 검색어·설정·성공·시간초과·차단 등 기록.
- `manifest.json`: 전체 범위와 한계.
- `README.md`: 이 안내.
CSV는 Excel에서 한국어가 잘 열리도록 UTF-8 BOM으로 저장했습니다. JSONL은 UTF-8입니다.

`record_id`는 이 자료에서 부여한 내부 ID입니다.
`platform_comment_id`만 해당 사이트가 제공한 ID입니다. 못 얻은 경우 비워두었습니다.
클리앙은 댓글 ID는 보존했지만 검증되지 않은 URL 앵커를 만들지 않아 게시글 URL을 사용합니다.
티스토리·디시인사이드의 내부 기록 ID를 해당 사이트의 영구 댓글 ID로 오해하지 마세요.
`parent_record_id`는 연결을 확인할 수 있을 때만 사용하며, 완전한 대화 트리를 제공하는 것은 아닙니다.
`published_display`는 화면 날짜 그대로이거나 확인된 표기입니다. 상대 날짜와 연도 미상의 날짜를 임의 변환하지 않았습니다.

## 자료를 해석하는 방법
이 자료는 검색어 기반의 탐색 표본이며, 모집단에서 무작위로 추출한 데이터가 아닙니다.
구독 고객의 이사 사례가 충분히 확보된 것이 아닙니다. 구매한 가전의 이전 경험과 비경험자의 질문·의견이 많이 섞여 있습니다.
구독 여부·제품 종류·완료 경험을 필터링해 사용하세요. 워시타워와 인접 제품의 사례를 구분해야 합니다.
한 게시글의 원글·답글이나 같은 작성자의 연속 댓글을 서로 다른 고객/피해 사건으로 집계하면 안 됩니다.

주제는 분석자가 부여한 질적 코드입니다. 다중 주제이므로 주제별 합계가 댓글 수보다 커질 수 있습니다.
협찬·브랜드 홍보·일반 정보·출처 불명의 가공 사례는 핵심 고객 경험 분석에서 제외했습니다.
비용과 할인 조건은 작성 당시의 개인 주장입니다. 현재 공식 정책·가격·계약상 권리로 사용하지 마세요.
피해 진술은 작성자 측 주장이지 업체 책임이 확정되었다는 증거가 아닙니다.
미검증 안전 조언을 운반 지침으로 사용하지 말고, 해당 모델의 공식 안내와 전문가 확인을 연결해야 합니다.

## 권장 사용
CX 문제 정의, 사용자 질문 목록, 인터뷰 가설, 기능 우선순위, Agent 테스트 시나리오의 재료로 사용하세요.
댓글·후기 기반 데이터는 공식 약관/정책 RAG와 별도 보관하는 것이 좋습니다.
발표에서는 “탐색적으로 수집한 공개 경험담과 질문에서 비용 범위, 문의 경로, 일정 조율, 설치 준비 이슈가 관찰됐다”라고 설명할 수 있습니다.
“LG 구독 고객 60명을 분석했다” 또는 “42명이 불만을 겪었다”라는 설명은 이 자료가 뒷받침하지 않습니다.

## 텍스트·개인정보 처리
이 패키지는 원문 전체 또는 영상 자막 전체의 복제본이 아닙니다.
실제로 읽힌 내용에서 필요한 정보만 짧게 요약하고, 원문 URL·댓글 ID를 남겼습니다. 두 개의 짧은 인용 외에는 원문 문장으로 소개하지 마세요.
닉네임·IP·이메일·상세 주소 및 비관련 신상 정보는 분석 내용에서 제거했습니다.
공개 원문 URL에는 플랫폼 경로상 계정명이 들어 있을 수 있으나, 별도 작성자 프로필이나 사람별 데이터베이스는 만들지 않았습니다.
수집 도구의 자동 질의 요약은 원문 자체가 아닙니다. 질의 추출만 확보한 자료는 출처 목록에 표시했습니다.
