# 기획안 요약

## 무엇을 만드는가

**LG Move Care**는 이사를 앞둔 워시타워 구독 고객이 해지와 이전을 비교하고, 이전을 선택하면 예약까지 진행하도록 돕는 AI Agent PoC다. 대상 제품을 워시타워 하나로 제한하여 제출일까지 하나의 전체 업무 흐름을 완성한다.

## 고객 문제와 해결 흐름

고객은 계약서, 위약금, 회수비, 무상 재설치 조건, 운송, 설치 가능 여부와 예약 일정을 여러 경로에서 확인해야 한다. Agent가 고객 계약을 조회하고 공개 규정을 검색한 뒤 코드로 비용을 계산하고 선택지를 설명한다. 예약은 설치환경·주소·일정 확인과 고객의 최종 동의 후 가상 시스템에서 처리한다.

핵심 도구는 `get_customer_contract`, `search_contract_terms`, `calculate_termination_cost`, `get_relocation_quote`, `manage_relocation_booking` 5개다. RAG는 근거 검색, MCP는 업무 데이터 조회·계산·상태 변경을 담당한다.

## 구현과 평가

React/TypeScript/Vite 화면, FastAPI 서버, LangChain Agent, ChromaDB RAG, FastMCP, SQLite Mock DB로 구성한다. 원안의 “Node.js 제거”는 별도 Node API 서버를 두지 않는다는 의미로 해석하는 것이 적절하다. Vite 프론트엔드 개발 도구에는 Node.js 런타임이 필요할 수 있다.

대시보드, 상담 진행 상태, 출처가 있는 비용 비교 카드, 예약 화면을 만든다. 정상·정보부족·예외·위험 상황 30개로 평가한다. 계산 정확도 100%, Tool·규정·인용 정확도 95% 등은 목표이며 아직 측정된 성과가 아니다. 이번 데이터 패키지도 Agent 실행 평가를 수행한 결과는 아니다.

## 수집 결과로 바로잡을 표현

1. **31.4%의 정확한 의미:** 설문 500명 중 157명이 ‘가전 구독 중도해지에 위약금이 없다고 인식’했다. ‘위약금 수준을 제대로 인지하지 못함’보다 이 표현이 원문에 정확하다. 설문은 2025년 11월 진행됐다. [보고서](https://www.kca.go.kr/smartconsumer/sub.do?menukey=7301&mode=view&no=1004452389), PDF 22쪽(본문 15쪽).
2. **조사와 발간 날짜 구분:** 수집한 보고서는 표지 2025.12, 공식 게시물 발간일 2026-04-09다. 따라서 ‘2026년 4월에 설문조사했다’고 표현하지 않는다. 기획안의 4월 8일 언론 발표일과 보고서 발간일을 구분한다.
3. **피해구제 2,624건의 범위:** 2022.1~2025.6에 설정된 품목·검색조건으로 집계된 가전 구독·렌탈 접수다. LG나 워시타워만의 피해도 아니며, 별도 4개사 약관조사의 표본 수와도 다르다. 계약 관련 1,446건(55.1%), 품질·AS 908건(34.6%). PDF 14쪽(본문 7쪽).
4. **이사 문제의 근거:** 보고서는 계약불이행 사례에 이전설치 불가·미이행을 포함하지만, 이사로 인한 피해 건수를 따로 제공하지 않는다. 이사는 서비스 적용 시나리오로 제시한다. PDF 15쪽(본문 8쪽).
5. **회수비와 혜택:** [LG FAQ](https://www.lge.co.kr/support/usage-guide-faq)는 2026-03-24 기준 워시타워 회수비 111,000원을 안내하며 계약서 금액 확인을 요구한다. [LG 재설치 안내](https://bestshop.lge.co.kr/story/insight/detail/IN10009002)는 해당 혜택의 운송 제외를 명시한다. 현재 안내를 과거 계약 모두에 소급 적용하지 않는다.

## 비교 결과를 어떻게 말할 것인가

가상 C001의 해지 323,400원과 이전 80,000원의 차이는 **이사 시 일회성 비용 차이 243,400원**이다. 이전하면 월 구독료가 계속 발생하고 해지하면 대체가전 비용이 들 수 있다. 총경제성 비교에는 동일한 비교 기간, 향후 구독료, 대체가전 구입·사용 비용, 소유권 이전 조건이 추가로 필요하다.

## 일정과 기대 가치

원안 일정은 10/12 데이터·CX 정의, 10/13 RAG·Mock·Tool, 10/14 웹 연동, 10/15 평가·발표 준비, **2026-10-16 금요일 오전 11시 제출**이다. 기대 가치는 고객 의사결정 지원, 반복 상담 감소, 구독 유지다. 실제 해지율·상담량 감소는 추후 실험으로 검증해야 한다.
