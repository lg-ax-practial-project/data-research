# 분석 방법과 활용 한계

## 서로 다른 세 종류의 근거

1. **실태조사 집계:** 한국소비자원이 선정 조건으로 집계한 2022.1~2025.6 피해구제 2,624건과 별도 설문 500명. 계약 문제의 중요성을 설명하는 근거다.
2. **공개 접수 원자료:** 2026년 2분기 전체 품목의 피해구제 12,834건. 여기서 프로젝트 관련 품목을 선택하여 청구이유·연령·처리결과를 분석할 수 있다.
3. **합성 계약·견적:** Agent 업무 시연용. 실제 고객의 분포·수요·불만 빈도에 대한 증거가 아니다.

이 자료들은 조사기간·표본·선정조건이 달라 하나의 행 테이블로 합쳐 비율을 계산하지 않는다.

## 보고서에서 얻을 수 있는 인사이트

- 계약 관련 1,446건은 2,624건의 55.1%다. 계약해지·위약금 950건은 **계약 관련 1,446건 중 65.7%**다. 전체 대비 비율은 별도 계산인 `950 / 2624 × 100 ≈ 36.2%`다.
- 전체 접수는 2022년 636건, 2023년 643건, 2024년 886건, 2025년 상반기 459건이다. 2025년 반기를 2024년 연간과 직접 비교해 증감을 판단하지 않는다.
- 정수기가 1,528건으로 다수를 차지한다. 세탁기 15건을 워시타워 구독 고객의 피해율로 해석할 수 없다. 전체 계약 수라는 분모도 없다.
- 500명 설문에서 위약금이 없다고 인식한 응답이 157명(31.4%), 추가비용 발생을 몰랐다는 응답이 139명(27.8%)이다. 계약별 비용 구성 설명의 필요성을 뒷받침한다.
- 계약불이행 사례에 이전설치 불가·미이행이 포함된다. 다만 이사 원인만 분리한 통계가 없어 “이사가 최대 원인”이라고 결론낼 수 없다.

출처: [한국소비자원 가전 구독·렌탈 서비스 실태조사](https://www.kca.go.kr/smartconsumer/sub.do?menukey=7301&mode=view&no=1004452389), 본문 7~8·15쪽(PDF 14~15·22쪽). 원문 표의 핵심 수치를 JSON으로 전사했고 해당 세 페이지를 시각적으로 확인했다.

## 공개 CSV 처리

원본의 물품명을 정확하게 일치시켜 `product_filter.json`의 10개 품목명을 선정한다. `세탁` 문자열 포함만으로 필터하면 의류 세탁서비스와 세제까지 섞이므로 사용하지 않는다. 선택한 10개가 모든 가전을 포괄하는 것은 아니다.

선정된 데이터의 집계는 `kca_public_profile.json`, 품목·사유·연령 교차집계는 `kca_product_reason_age.json`에 있다. 누락값은 원본대로 보존하며, 동일 속성 행이 실제로 다른 접수일 수 있어 중복 삭제하지 않는다. 원본 행 번호는 추적용이지 공식 사건 ID가 아니다.

이번 선정 결과는 291건이다. 전기세탁기 31건, 전기의류건조기 8건, 냉장고 33건, 김치냉장고 15건, 에어컨 4개 분류 합계 60건, 정수기 24건, 정수기대여 120건이다. 선정 집합에서 계약해제·해지/위약금은 62건, 계약불이행은 41건이다. 이는 프로젝트가 정한 10개 품목의 2026년 2분기 기술통계이며, 구독 고객 전체 통계나 보고서의 55.1%를 재현한 결과가 아니다.

전체 원본의 지역 공란은 537건, 판매유형 공란은 3건이다. 연령의 `불명` 같은 문자열은 공란 수에 포함되지 않으므로 별도 범주로 해석해야 한다.

이 데이터에는 LG 브랜드, 워시타워 모델, 이사 여부, 계약기간, 실청구금액이 없다. 구매형과 렌탈형을 완전히 구분할 수 없으므로 “가전 구독 피해”로 전부 이름 붙이면 안 된다. 특히 판매유형은 구독 여부가 아니다. 일반 세탁기 접수 분석은 배경 자료로 활용한다.

## 규정 데이터 처리

공개 FAQ와 혜택 안내는 계약별 판단을 위한 참고 자료다. 위약금 30/20/10%는 LG 공개 안내 수치이며 법적 최종 정산액 판정이 아니다. 소비자원 보고서에는 분쟁해결기준 대비 높은 위약금에 대한 지적도 있다. 고객 계약, 최신 규정, 분쟁 사유가 충돌하면 자동 확정하지 않고 확인 필요로 전환하는 것이 적절하다.

계산 시점의 실제 일수·일할 정산·반올림·경계일·가입채널·특약·약관 버전은 미확보다. Mock은 완전한 개월 단위만 사용한다. 계약별 최종 정산 엔진으로 배포하려면 이 입력을 추가 확보해야 한다.

## 추가 데이터 우선순위

1. 실제 서비스 범위에 맞는 워시타워 모델 선정 및 해당 모델 설치 설명서.
2. 개인정보를 제거한 계약서 샘플 또는 LG 제공 버전별 구독 약관. 가입일·채널·시행일과 연결.
3. 철거·운송·재설치가 분리된 실제 견적 샘플. 지역·거리·층수·엘리베이터·특수 작업별 조건.
4. 이사 경험 구독자 인터뷰 또는 설문. 계약 이해·절차 번거로움·실제 선택 기준 확인.
5. 공개 피해구제 과거 분기 자료. 컬럼·분류 변경을 확인한 후 동일 품목 기준 시계열 구성.

현재 묶음은 데이터 조사와 PoC 착수에 필요한 원본·가공 자료·가상 시드를 제공한다. 실제 LG 연동 및 Agent 구현·성능 평가는 포함하지 않는다.
