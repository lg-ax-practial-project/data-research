# CX Planning

LG전자 CX 핵심 프로젝트의 **기획 및 조사 자료를 관리하는 Repository**입니다.

프로젝트 주제 선정부터 데이터 분석, CX 문제 정의, 사용자 시나리오, AI Agent 설계에 필요한 근거 자료를 관리합니다.

## 주요 내용

- CX 문제 정의 및 프로젝트 기획
- 공공데이터 분석 및 인사이트
- 소비자분쟁해결기준 등 관련 자료 조사
- LG 기존 서비스/챗봇 분석
- AI Agent 기능 및 시스템 설계
- 프로젝트 산출물 및 참고자료

> 실제 서비스 구현 코드는 `cx-agent` Repository에서 관리합니다.
