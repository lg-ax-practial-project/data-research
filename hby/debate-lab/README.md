# debate-lab — LG 홈라이프 Vision AI Agent 아이디어 토론 기록

LG AX 실전 프로젝트에 제안할 **고객 경험(CX) 중심 Vision AI Agent 서비스 아이디어**를 찾기 위해
세 AI(Claude Code, OpenAI Codex, Antigravity CLI `agy`)가 4라운드 동안 토론한 기록입니다.
그 결과를 다른 두 모델(Astra, Fable)이 따로 검증했습니다.

> ⚠️ 이 저장소의 모든 내용은 **개인 탐색 자료**입니다.
> AI 간 합의나 점수는 팀의 공식 결정이 아니며, 고객 수요 등은 **검증되지 않은 가설**입니다.

## 📌 한눈에 보는 결론

세 AI가 고른 조사 우선순위 후보입니다. 순위는 **"먼저 조사할 순서"이며 채택 권고가 아닙니다.**

| 공식 주제 | Claude Code | Codex | AGY |
|---|---|---|---|
| ② 이사 가전 플래너 | 2순위 `C01` 이사 가전 왕복 기록 | `E01` 변경 설치 조건 재확인 | 1순위 `CAND-01` 설치 조건 Diff 플래너 |
| ④ 세탁 케어 코치 | 1순위 `C03` 세탁 예외 의류 등록·재식별 | `E02` 세탁 예외 의류 연결 | 2순위 `CAND-03` 세탁 위험군 역지목·건조 인계 |
| ⑥ 가전 교체 타이밍 | 3순위 `C02` 고장 접수 패킷 | — | 3순위 `CAND-02` 자가점검 여과 + TCO 비교 |
| ⑤ 로봇청소기 코치 | 4순위(조건부) `C04` 청소 실패 수정·재시험 | `E03` 청소 수정·재시험 | 4순위 `CAND-04` 주행 지도–사진 대조 |
| ⑦ 홈가드닝 | — | `E04` 식물 돌봄 역인계 | 후순위 |

**독립 검증 결과**

- **Fable**: 조사 순서로 `E02`(세탁) → `E01`(이사, 데이터 확보가 조건) → ③ 냉장고 재검토 → ⑥ 축소안 → `E03`(청소, 장비가 조건)을 제안했습니다.
  "주제는 겹쳤지만 서비스 정의는 갈려 있고, 고객 수요 근거는 0건"이라고 지적했습니다.
  공식 배점 중 LangGraph·검증·배포 영역이 토론 기준에 약하게 반영됐다는 점도 짚었습니다.
- **Astra**: 판정은 **"조건부 조사 진행, 최종 채택 근거는 부족"** 입니다.
  조사 순서는 `E01` → `E02` → `E07`(실물 샘플 비교) → `E04` → `E03`입니다.

자세한 근거는 위 파일 1~3을 보세요.

## 🔁 토론 라운드와 발언 파일

파일 이름 규칙은 `r{라운드 번호}_{참가자}.md` 입니다. 참가자는 `claude`, `codex`, `agy` 중 하나입니다.

| 라운드 | 내용 | 파일 |
|---|---|---|
| Round 1 | **독립 아이디어 발굴.** 다른 참가자 결과를 보지 않고 20~30개씩 제안 | `r1_*.md` |
| Round 2 | **상호 반론.** 약한 고객 문제, 중복, Vision AI가 불필요한 경우 지적 | `r2_*.md` |
| Round 3 | **재설계·융합.** 살아남은 후보를 발전시키고 결합 | `r3_*.md` |
| Round 4 | **비교·정리.** 잠정 점수와 조사 우선순위 제안 → `FINAL_REVIEW_RECOVERED.md`로 통합 | `r4_*.md` |

발언 안의 ID(`R3-CL F2`, `CX-R4-CODEX-003`, `AGY-R3-F01` 등)는 참가자별 발언·아이디어 식별자입니다.
다른 파일에서 같은 ID로 검색하면 원래 발언을 찾을 수 있습니다.

## 📝 토론 주제 요약

- **주제**: LG 홈라이프 Vision AI Agent 신규 서비스 아이디어 발굴
- **문제의식(가설)**: 고객은 정보를 알아도 상황 확인·비교·판단·신청·실행이 번거로워 행동하지 못한다. AI Agent가 이 부담을 줄일 수 있다.
- **공식 주제 8개**: ① 오브제컬렉션 인테리어 코디 ② 이사 가전 플래너 ③ 냉장고 식재료·식단 플래너 ④ 세탁 케어 코치 ⑤ 로봇청소기 청소 준비 코치 ⑥ 가전 교체 타이밍 어드바이저 ⑦ 홈가드닝 식물 케어 코치 ⑧ 우리 집 에너지 절감 코치
- **공식 과제 조건**: 사진 기반 상황 분석과 추가 촬영 요청, LangGraph 기반 Agent, 작업 상태·결과·이력 UI, 클라우드 배포, 데이터 기반 평가

> 토론 실행 스크립트, 프롬프트, 원본 참고 자료(팀원 아이디어 문서 등)는 이 저장소에 포함하지 않았습니다.
