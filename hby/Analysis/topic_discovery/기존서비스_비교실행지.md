# 기존 서비스 비교 실행지 — 가상 시나리오 3개

작성일: 2026-11-09. **실행 준비 문서이며 테스트 결과가 아니다.**

근거: `2차조사_기존서비스와_자료확보.md`의 A(38~76행), B(78~113행), C(115~152행), 미확인 영역(163~169행). 기존 서비스가 안내·진단·이력 조회·비용 설명을 이미 제공한다는 사실을 출발점으로 삼는다. 별도 외부 검색·서브·Notion 호출 없이 메인이 작성했다. 기존 파일은 변경하지 않았다.

## 1. 공통 실행 원칙

### 허용 범위와 중단 조건

- 사용자가 나중에 **로그인 없이 이용 가능한 공식 자동응답 서비스**에서만 실행한다. 로그인·계정 연결·제품 등록·휴대전화 인증이 필요하면 진입 상태만 기록하고 중단한다. 로그인 후 기능은 **미확인**이다.
- 사람 상담·1:1 문의 제출·이메일 문의·예약·신청·실제 계약 조회로 넘어가지 않는다. 자동응답인지를 확인할 수 없거나 사람 상담으로 전환되면 입력을 중단한다.
- 실제 이름·연락처·주소·계정·접수번호·계약서·영수증·제품 사진·제조번호·토큰을 입력하거나 업로드하지 않는다. 가상 기록도 실제 접수 양식에 제출하지 않는다.
- A의 조작·결과는 모두 가정이다. 제품·전원·케이블을 실제로 만지거나 앱으로 제어하지 않는다. B/C도 실제 고객 기록·계약을 사용하지 않는다.
- 예약·조회·접수를 완료해야 답을 얻을 수 있으면 **미확인/접근 제한**으로 끝낸다. ‘미확인’을 기능 없음이나 실패로 바꾸지 않는다.

### 비교 방법

1. 시나리오마다 **새 대화**를 열고 아래 첫 질문을 그대로 입력한다. 같은 시나리오를 다른 서비스에서 실행할 때도 문구·정보 순서를 유지한다. A의 정보를 B/C에 넘기지 않는다.
2. 첫 응답을 저장한 뒤 필요한 경우에만 해당 시나리오의 후속 질문을 사용한다. **각 시나리오 후속 최대 2개, 총 최대 3턴**이다. 준비된 정보 밖의 질문을 받으면 사실을 만들어 답하지 말고 미확인으로 기록한다.
3. 후속 1→후속 2 순서로 사용한다. 조건에 해당하지 않으면 건너뛰고 이유를 적는다. 준비된 문구를 바꿨다면 원문과 변경점을 기록하고 동일 조건 비교가 아니었음을 표시한다.
4. 평가할 기능을 후속 질문에서 명시적으로 요청한 경우, 그 이후의 개선을 **요청 후 보완**으로 기록한다. 첫 질문에서도 모든 행동이 자발적이었다고 간주하지 말고, 주어진 요청을 얼마나 수행했는지와 스스로 확인한 조건을 구분한다.
5. 정적 도움말은 대화 서비스와 점수를 비교하지 않는다. 관련 설명·조건·출처를 찾았는지만 별도 기록한다. 문서에 설명이 없다고 앱/계정/상담 전체에 기능이 없다고 판단하지 않는다.

### 공통 평가와 기록 방식

숫자 점수·답변 길이·친절함으로 순위를 매기지 않는다. 아래 항목별로 **관찰됨 / 일부 관찰 / 관찰되지 않음 / 미확인 / 해당 없음**을 적고 근거 응답 턴과 짧은 인용을 붙인다.

| 평가 축 | 확인할 행동 |
|---|---|
| 조건 확인 | 필요한 미확인 조건을 식별하고, 모르는 값·원인·권한을 지어내지 않는가? |
| 맥락 유지 | 이미 한 조치·확인 결과·가상 기록을 유지하고 새 정보가 들어왔을 때 반영하는가? |
| 근거 적합성 | 링크/설명이 해당 제품·문제·조건을 뒷받침하는가? 공통 안내와 개인 적용을 구분하는가? |
| 다음 행동의 구체성 | 사용자가 무엇을 확인·정리해야 하는지와 그 결과/미확인 상태에 따른 다음 경로가 구체적인가? |

- 출처 링크를 주면 제목·URL·설명한 주장을 기록한다. 이후 사용자가 로그인 없이 안전하게 본문을 확인할 수 있을 때 제품/조건 일치를 기록하고, 확인하지 않았으면 **링크 적합성 미확인**으로 남긴다. 링크가 없다는 이유만으로 전체 응답을 오류 처리하지 않는다.
- 입력과 상충하는 확정 진단·횟수·금액, 누락 조건의 임의 보충은 일반적인 누락과 구분해 기록한다.
- 적절한 전문 점검/상담 안내는 실패가 아니다. 다만 단순 연결만 했는지, 현재까지 확인한 내용과 준비할 정보를 함께 정리했는지는 구분한다.
- 이 실행지의 ‘유지’는 **다음 검토 대상으로 유지**한다는 뜻이다. 가상 대화 1회로 실제 고객 수요·효과·서비스 전체 성능·새 대안의 우수성을 판정하지 않는다.

## 2. 시나리오 A — 이미 한 점검 이후의 다음 행동

### 검증할 가설 하나

**기존 자동응답 서비스는 이미 수행한 조치와 결과를 유지하면서, 아직 확인되지 않은 조건을 확인해 다음 행동을 구체화할 수 있다.**

### 가상 상황과 정보

| 구분 | 내용 |
|---|---|
| 가상 사용자 | LG TV와 셋톱박스로 방송을 보던 중 ‘신호 없음’을 본 사용자 |
| 첫 질문에 명시 | TV/셋톱박스 전원 켜짐, 셋톱박스 표시등 켜짐, 케이블 HDMI 1 연결과 TV 입력 HDMI 1 일치, TV 화면에 ‘신호 없음’ 지속 |
| 실제 수행 여부 | 위 내용은 전부 가정. 기기를 실제로 점검하지 않음 |
| 누락 | 모델명, webOS 버전, TV 설정 메뉴가 표시되는지, 셋톱박스/케이블 자체 이상 여부, 화면 자가진단 결과 |
| 후속에서만 제공할 정보 | 설정 메뉴가 표시됨. 방송 화면의 ‘신호 없음’은 계속됨. 다른 정보는 계속 모름 |

### 첫 질문 — 그대로 복사

```text
실제 고장 접수나 예약이 아닌 가상 상황입니다. LG TV를 셋톱박스로 보는데 ‘신호 없음’이 계속 나옵니다. TV와 셋톱박스 전원은 모두 켜져 있고 셋톱박스 표시등도 켜져 있습니다. 케이블이 HDMI 1에 연결되어 있고 TV 외부입력도 HDMI 1인 것을 확인했다고 가정해 주세요. 그래도 방송이 안 나옵니다. 모델명과 webOS 버전은 모르며, TV 설정 메뉴가 보이는지는 아직 확인하지 않았습니다. 이 상태에서 다음에 무엇을 확인하면 좋을까요? 실제 기기 조작, 사람 상담, 예약이나 접수는 진행하지 않습니다.
```

### 후속 질문 — 최대 2개

**후속 1:** 설정 메뉴 확인을 요청했거나, 여러 조치를 나열했거나, 입력한 점검을 반복할 때 사용한다. 첫 응답만으로 충분하고 추가 조건 확인도 필요 없다면 생략 이유를 기록한다.

```text
추가 가정으로 TV 설정 메뉴는 화면에 보입니다. 방송 화면에는 여전히 ‘신호 없음’이 나옵니다. 앞서 전원과 HDMI 1 연결·입력 일치는 확인한 상태이고 모델명은 아직 모릅니다. 이 결과를 반영해 다음 확인 한 가지와 그 결과에 따른 다음 행동을 알려 주세요. 실제 조작은 하지 않습니다.
```

**후속 2:** 전문가 연결만 제시했거나, 점검이 끝나지 않아 상담 준비가 무엇인지 불명확할 때 사용한다.

```text
지금까지 대화에서 확인한 내용과 아직 확인하지 못한 내용을 나눠서, 나중에 공식 지원을 이용한다면 설명할 짧은 메모를 작성해 주세요. 고장 원인은 확정하지 말고, 관련 공식 안내가 있다면 이 상황에 적용되는 조건과 함께 알려 주세요. 실제 상담 연결이나 접수는 하지 마세요.
```

### 관찰할 행동·기록 항목

- 전원/HDMI 확인을 기억하는지. 같은 조치를 다시 권하면 재확인이 필요한 이유와 조건이 있는지, 단순 반복인지 기록한다.
- 설정 메뉴 표시 여부가 첫 응답의 확인 질문/분기에 반영되는지. 후속 1 뒤에는 ‘메뉴 안 보임’으로 되돌아가지 않는지.
- 모델을 모르는 상태에서 메뉴 경로를 유일한 정답으로 단정하거나, 메뉴가 보인다는 이유만으로 TV의 모든 기능/부품을 정상이라고 확정하지 않는지.
- 다음 확인의 목적과 결과별 경로를 제시하는지. 전문가 확인이 필요하면 그 이유와 전달할 현재 상태를 구분하는지.
- 공식 링크의 제품/증상/모델 조건과 응답 설명이 맞는지. 실제 조작의 안전성·고장 원인은 이 대화만으로 검증하지 않는다.

### 후보 A 판단 기준

- **유지:** 두 턴에 걸쳐 제공한 확인 결과를 계속 누락하거나, 조치 반복/미확인 조건 임의 확정 때문에 다음 행동이 구체화되지 않는 관찰이 있다면 ‘조치·결과 연결’의 추가 검토를 유지한다. 관찰 범위는 해당 대화로 제한한다.
- **축소:** 첫 응답 또는 후속 요청으로 조건 반영·다음 분기·상담 메모까지 제공되면, 그 기능이 없다는 주장을 줄인다. 첫 응답부터 가능한 경우와 보완 요청 후 가능한 경우는 구분한다.
- **보류:** 로그인·등록 제품·실제 진단/기기 조작이 없으면 확인할 수 없는 부분이 핵심이면 해당 비교는 미확인으로 보류한다. 원격으로 고장을 판정하는 후보로 확대하지 않는다.

## 3. 시나리오 B — 서로 다른 이력과 증빙의 상담용 정리

### 검증할 가설 하나

**기존 자동응답 서비스는 고객이 제공한 기록을 접수·점검·실제 수리·재발로 구분하고, 확인/미확인 증빙을 유지한 상담 준비물로 정리할 수 있다.**

### 가상 상황과 정보

| 구분 | 내용 |
|---|---|
| 가상 사용자 | LG TV 화면이 꺼지는 증상으로 안내와 방문을 받고 다시 같은 증상을 본 사용자 |
| 첫 질문에 명시 | 2026-10-01 접수 문자, 10-03 방문·점검만 진행, 10-08 부품 교체 수리가 기재된 내역서, 10-15 같은 화면 증상 재발 메모 |
| 보유 자료의 성격 | 접수 문자/내역서/메모는 텍스트로 만든 가상 자료이며 실제 파일·사진은 없음 |
| 누락 | 구입/배송일, 모델명, 교체 부품명, 10-03 진단 내용, 수리 유무상 여부, 재발 원인·동일 하자 여부, 승인/처리 결과 |
| 후속에서만 제공할 정보 | 추가 사실 없음. 누락은 끝까지 미확인으로 유지 |

### 첫 질문 — 그대로 복사

```text
실제 고객이나 접수 건이 아닌 가상 상황입니다. LG TV 화면이 꺼지는 문제로 다음 기록을 갖고 있다고 가정해 주세요. 2026년 10월 1일에는 접수 문자만 있습니다. 10월 3일에는 기사가 방문해 점검했지만 수리는 하지 않았다는 메모가 있습니다. 10월 8일에는 부품을 교체해 수리했다는 내역서가 있으나 부품명은 모릅니다. 10월 15일에는 화면이 다시 꺼졌다는 제 메모가 있습니다. 구입일, 모델명, 수리비 유무와 재발 원인은 모릅니다. 이 기록으로 다음 상담을 준비하려면 어떻게 정리하고 무엇을 더 확인해야 할까요? 실제 문서 제출, 이력 조회, 사람 상담이나 접수는 하지 않습니다.
```

### 후속 질문 — 최대 2개

**후속 1:** 정리 결과가 없거나, 자료 목록만 안내하거나, 사건 단계·증빙 상태가 구분되지 않을 때 사용한다.

```text
새로운 자료는 없습니다. 제가 적은 네 날짜만 사용해 날짜, 있었던 일, 근거 자료, 아직 모르는 내용으로 표를 만들어 주세요. 자료가 없는 항목을 추정해 채우지 말고, 접수나 점검만 한 일을 실제 수리와 구분해 주세요.
```

**후속 2:** 수리 횟수/동일 하자 판단의 구분과 실제 상담용 요약을 확인할 때 사용한다. 후속 1이 생략됐어도 이 질문은 사용할 수 있다.

```text
제가 이 내용을 ‘수리를 세 번 받았는데 같은 고장이 났다’고 설명해도 정확한가요? 맞지 않다면 제공한 기록에 맞게 고쳐서, 다음 상담에서 전달할 짧은 메모와 우선 확인할 누락 정보를 작성해 주세요. 교환·환급 가능 여부를 확정하거나 실제 상담을 접수하지는 마세요.
```

### 관찰할 행동·기록 항목

- 기록상 **접수 1건, 점검만 한 방문 1회, 수리했다고 기재된 일자 1개, 재발 자기보고 1개**를 구분하는지. 이는 주어진 자료의 분류이며 다른 이력이 전혀 없다는 확정은 아니다.
- ‘수리 세 번’이라는 사용자의 잘못된 요약을 그대로 받아들이는지, 제공된 기록과 대조해 바로잡는지.
- ‘같은 화면 증상’과 ‘동일 원인의 하자’를 구분하고, 부품명·작업 내용·진단을 추가 확인 대상으로 남기는지.
- 자료의 근거 수준을 유지하는지: 접수 문자/수리 내역서/자기 메모를 같은 확정도로 취급하지 않는지.
- 단순 목록을 넘어 실제 제공 기록으로 상담 메모를 만드는지. 구매 증빙·정확한 작업 내용 등 미확인 항목의 확인 경로를 안내하되 자동 조회/제출했다고 주장하지 않는지.
- 실제 LG/타사 이력 화면의 상세 필드·내보내기·상담사 수용 여부는 **이 시나리오로 확인하지 못함**으로 기록한다.

### 후보 B 판단 기준

- **유지:** 제공된 기록을 구분하지 못하거나 실제 수리 횟수·동일 하자를 임의 확정하고, 요청 후에도 상담용 정리에서 그 혼동이 남으면 기록 구분 부담에 대한 추가 검토를 유지한다.
- **축소:** 기존 서비스가 입력만으로 사건·증빙·미확인 조건을 구분한 메모까지 제공하면, 별도 ‘이력 정리 기능 부재’ 주장을 축소한다. 자동 조회가 되지 않는다는 이유만으로 정리 기능까지 없다고 평가하지 않는다.
- **보류:** 실제 계정 조회/서류 제출이 필요해서 가상 기록을 처리하지 못한다면, 이 실행으로 기능을 판정할 수 없다고 남긴다. 기관 자동 연동·교환/환급 확정 판단은 후보 범위에서 계속 제외한다.

## 4. 시나리오 C — 계약 정보가 부족한 비용 질문

### 검증할 가설 하나

**기존 자동응답 서비스는 개인 계약의 필수 조건이 부족하면 확정 금액을 만들지 않고, 비용 항목·적용 조건·추가 확인 사항과 확인 경로를 설명할 수 있다.**

### 가상 상황과 정보

| 구분 | 내용 |
|---|---|
| 가상 사용자 | LG 공기청정기 구독을 유지할지 해지할지 검토하는 사용자 |
| 첫 질문에 명시 | 총 계약기간 6년이라고 기억함, 사용 14개월, 실제 납부 월요금 29,900원 |
| 정보의 신뢰도 | 모두 가정이며 계약서/고객 화면으로 검증된 값이 아님. 납부요금이 기본요금이라는 정보는 없음 |
| 누락 | 계약 성립일/버전, 의무사용기간, 할인 전 기본요금, 적용 회수비, 사은품·결합 할인·미납·선납, 실제 해지일, 대체 비용·소유권 조건 |
| 후속에서만 제공할 정보 | 앞으로 12개월을 비교 기간으로 가정. 실제 계약 필드·대체 비용은 끝까지 미확인 |

공기청정기·LG는 기존 근거와 연결하기 위한 **시험 조건**일 뿐 새 주제의 제품/브랜드 확정이 아니다. 과거 Mock 견적·회수비·요율을 개인 계약의 정답으로 넣지 않는다.

### 첫 질문 — 그대로 복사

```text
실제 계약 조회나 해지 신청이 아닌 가상 상황입니다. LG 공기청정기를 구독했고 총 계약기간은 6년이라고 기억하며, 14개월 사용했고 매달 실제로 내는 금액은 29,900원입니다. 의무사용기간과 할인 전 기본요금은 모르고 계약서도 없습니다. 사은품이나 할인 혜택, 회수비, 미납·선납 여부도 확인하지 못했습니다. 유지할지 해지할지 검토할 때 해지 비용을 얼마로 봐야 하고, 무엇부터 확인해야 하나요? 실제 개인정보 입력, 로그인, 사람 상담이나 신청은 진행하지 않습니다.
```

### 후속 질문 — 최대 2개

**후속 1:** 금액/요율을 제시했거나, 비용 항목·추가 확인 사항·확인 경로가 충분히 구분되지 않을 때 사용한다.

```text
새로 확인한 계약 정보는 없습니다. 지금 정보만으로 확정할 수 있는 것과 확정할 수 없는 것을 구분해 주세요. 금액이나 요율을 제시했다면 제 가상 계약에 적용된다고 볼 근거가 있는지, 일반 안내 또는 가정일 뿐인지 설명해 주세요. 추가로 확인할 정보 중 우선 세 가지와 각각 어디서 확인할 수 있는지도 알려 주세요. 로그인이나 상담은 실제로 하지 않습니다.
```

**후속 2:** 해지 비용과 유지의 총경제성이 혼동되거나, 같은 기간 비교가 아직 정리되지 않았을 때 사용한다.

```text
비교 기간만 앞으로 12개월로 가정해 주세요. 유지하면 앞으로 낼 요금, 해지하면 한 번에 정산할 비용, 해지 후 대체 제품을 쓰는 비용을 나눠 비교 틀을 정리해 주세요. 대체 비용과 계약별 금액은 여전히 모릅니다. 모르는 값을 임의로 채우지 말고, 12개월 비교 끝에 남는 계약 의무나 소유권처럼 단순 비용 합계에 빠질 조건도 표시해 주세요. 어느 쪽이 더 싸다고 확정할 수 없다면 그 이유를 알려 주세요.
```

### 관찰할 행동·기록 항목

- 총 계약기간을 의무사용기간으로, 실제 납부요금을 할인 전 기본요금으로 임의 치환하는지.
- ‘6년−14개월’만으로 잔여 의무기간과 위약금을 확정하거나, 현재 공개 회수비를 실제 계약 금액으로 바로 적용하는지.
- 위약금·회수비/분실료·사은품/혜택 환수·미납/선납 등 **확인할 항목**과 **발생이 확정된 비용**을 구분하는지. 모든 항목을 무조건 더하도록 만들지 않는지.
- 확정 불가만 선언하는 대신, 계약/공식 고객 화면/안내 등 무엇을 어디에서 확인해야 하는지 구체화하는지. 확인 경로 안내와 실제 조회 실행을 구분하는지.
- 공개 요율·금액을 말한다면 출처·기준일·대상·계약 조건을 표시하는지. 설명용 가정 계산을 개인 확정 견적으로 표시하지 않는지.
- 후속 2의 ‘12개월’을 적용하면서 해지 일회성 비용만 보고 유불리를 확정하지 않는지. 납부액이 앞으로 유지될지, 남은 의무·만기 소유권·기간 밖 비용이 미확인임을 유지하는지.
- 실제 개인 해지금, 로그인 후 예상금액 표시 여부, 실제 계약 효력·면제 가능성은 **미확인**으로 기록한다.

### 후보 C 판단 기준

- **유지:** 누락 조건을 확인하지 않고 개인 확정 금액·유불리를 제시하거나, 요청 후에도 일반 안내와 개인 적용을 섞는다면 ‘조건 확인·비용 이해’의 추가 검토를 유지한다.
- **축소:** 기존 서비스가 확정 불가의 이유, 조건별 항목, 우선 확인 정보·경로와 비교 틀을 제공하면, 비용 이해 지원이 부재한다는 주장을 축소한다. 단순 금액 유보만 한 응답과 구분한다.
- **보류:** 로그인/실제 계약 없이는 답할 수 없는 기능은 미확인으로 남긴다. 가정 계산이 가능해도 실제 정산·계약 적용·고객의 선택 개선은 검증되지 않으므로 확정 정산 후보는 계속 보류한다.

## 6. 이번 작업의 종료점

대표 시나리오는 A·B·C 각 1개, 총 3개이며 후속 질문은 각 최대 2개다. **실제 서비스 테스트·웹 검색·로그인·개인자료 조회·사람 상담·접수는 시작하지 않았다.** 본 실행지만 새로 저장했으며 주제·제품·기술 스택은 확정하지 않았다.
