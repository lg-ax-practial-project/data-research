# 주제선정 준비 — 기존 자료 1차 검증 인사이트

작성일: 2026-11-09. 개인 분석이며 팀의 주제·제품·기술 결정이 아니다.

**요약:** 기존 자료는 ‘무조건 새로운 상담 챗봇이 필요하다’보다 **이미 시도한 행동·이력·계약 조건을 확인하고 다음 행동을 결정하는 문제**를 탐색할 근거를 제공한다. 다만 실제 수요 규모와 기존 서비스 대비 추가 가치는 아직 입증되지 않았다.

## 1. 핵심 발견

### 1) ‘가전 피해 증가’와 ‘품질·A/S 청구 증가’는 다른 주장이다 — I01

| 원자료 재계산 | 2024년 | 2025년 | 증감 |
|---|---:|---:|---:|
| 선정 가전 피해구제 | 2,392 | 2,298 | -3.93% |
| 그중 품질·A/S 일반 청구 | 1,182 | 1,475 | +24.79% |
| 전체 피해구제 | 57,657 | 63,671 | +10.43% |

- **사실:** 10개 분기 CSV의 150,964행을 다시 읽고, 기존 25개 원문 품목명으로 선정 가전 5,554행을 재현했다. 품질(물품/용역) 1,969행 + AS불만 1,236행 = 3,205행(57.71%)이다.
- **해석:** 전체 가전 건수의 변화와 그 내부의 청구 구성 변화는 분리해야 한다. ‘가전 문제가 전반적으로 증가한다’는 문장은 이 자료와 맞지 않는다.
- **다른 설명:** 품목 구성·신청 성향·접수 경로·시장 규모의 변화는 분리하지 못했다. 분쟁 증가를 제품 고장률 증가로 바꿀 수 없다.
- **강도:** 선정 범위의 수치에는 충분. 세부 반복 고장·수리 지연 수요 해석에는 근거 부족.
- **출처:** `인사이트_근거표.csv` I01, `검증_v3\피해구제_연도별.csv` 및 `피해구제_원본파일별.csv`.

### 2) 중요한 것은 ‘설명을 더 많이’보다 ‘무엇을 했고, 그다음 무엇을 할지’일 수 있다 — I02·I06

- **사실:** 에어컨 유튜브 기존 표본 400행 중 기존 라벨로 LG 에어컨 본인 문제 100행이 선별돼 있다. 원인 모름 22행·다음 행동 모름 13행·사용법 모름 33행이라는 집계를 재현했다. 이는 **기존 AI 라벨 재집계**다.
- **원문 사례:** `표본 분류결과!H160`은 차단기를 다시 조작해도 냉방 문제가 지속된다고 서술한다. `H6`은 서비스센터 설명을 들은 뒤에도 사용해도 되는지 묻는다. 반면 `H40`은 여는 방법을 이해했다고 감사한다.
- **서비스 관찰:** TV S02 가상 질문은 리모컨을 구분하지 못한다고 명시하지만, 보존 응답은 리모컨 입력 버튼과 메뉴 조작부터 안내한다. 원인 분기와 증상 지속 질문 자체는 이미 제공한다.
- **해석:** 조치 이력·조작 가능 조건·현재 결과를 받아 다음 행동에 연결하는 문제가 탐색 대상이다.
- **다른 설명:** 온라인 글은 불만·고장 경험에 치우칠 수 있고, 영상 설명만으로 충분한 사례도 존재한다. S02는 가상 관찰 1회이지 실제 수행 실패가 아니다.
- **강도:** 제한적. 35/100을 전체 고객의 판단 어려움 비율로 사용하지 않는다.

### 3) 자가 점검을 확대하기 전에 ‘도움·의향·수행 중 막힘·새 이상’을 구분해야 한다 — I03

기존 요약의 ‘AS 대신 해결 2건’, ‘자가 시도가 새 문제 6건’을 그대로 검증 완료 수치로 가져오면 안 된다.

| 가공 시트의 위치 | 원문에서 확인한 내용 | 이번 판단 |
|---|---|---|
| 유튜브3차 H107/R107 | 앞으로 먼저 점검하고 문제가 생기면 기사를 부르겠다는 말 | 해결 경험이 아니라 미래 의향 |
| H247/R247 | 누락 부품을 찾아 잘 사용 중이라는 말 | 해결 자기보고는 있음. 실제 AS회피·절감 효과 미검증 |
| H59/T59 | 분해 중 송풍팬이 빠지지 않는다는 질문 | 수행 중 막힘. 새 고장 발생으로 확정할 수 없음 |
| H21/T21 | 조립 후 블레이드가 반대로 동작한다는 말 | 조치 후 새 이상 자기보고. 인과 진단은 아님 |
| H40/N40 | 여는 방법을 알게 됐다고 감사 | 안내가 도움이 되는 반례 |

- **해석:** ‘모두 자가 해결시키기’보다 수행 가능 범위와 전문가 확인으로 전환할 조건을 분명히 하는 문제를 탐색할 수 있다.
- **강도:** 사례 존재는 제한적 근거. 안전 기준·사고율·상담 감소 효과는 미확인.
- **주의:** 댓글 속 분해·전기 조작을 권장 절차로 재사용하지 않는다.
- **선정 방식:** 기존 라벨별 앞 2행과 해결 반례를 목적 선정했다. 무작위 품질평가가 아니며 라벨 오류율을 계산하지 않는다.

### 4) 반복 고장의 상담 준비는 ‘수리 몇 번’이 아니라 이력 구분 문제다 — I04·I05

- **사실:** 표준답변 전체 1,332항목 중 TV 26항목을 원본 CSV에서 재추출했다. 23번은 수리 2회 후 재발, 24번은 A/S센터 방문 3회와 서로 다른 하자, 12번은 구입가 증빙 부족을 묻는다. 26번은 낙하로 인한 고장이므로 정상 사용 사례와 구분해야 한다.
- **서비스 반례:** S05 보존 응답은 이미 구입일·수리 내역·방문일·작업 내용·현재 증상 자료와 고객센터 연결을 안내한다.
- **해석:** 단순 증빙 목록보다 접수→점검→실제 수리→재발과 확보/미확보 증빙을 구분하는 작업이 추가 가치 후보다.
- **한계:** 표준답변은 편집된 템플릿이다. 문의 빈도, 실제 첫 고장 고객 수, 이력 정리의 실제 어려움은 알 수 없다. 이번에는 주요 TV 질문 9개를 직접 읽었으며 26개 전체의 의미 분류를 다시 끝낸 것은 아니다.
- **강도:** 목록 안내가 이미 있다는 사실은 해당 응답 범위에서 충분. 추가 가치·사용자 요구는 가설.

### 5) 상담 이관 자체보다 ‘이미 한 문의를 다시 시키는지’가 구체적인 검토 질문이다 — I07

- **재집계:** 구글플레이 답변 분류 3,033행 중 직접 해결정보 99행(3.26%), 이관 991행(32.67%), 장애 공지 1,597행이다. 이는 기존 규칙 라벨을 재현한 것이지 적정성 점수가 아니다.
- **원문 사례:** `구글플레이 답변분류!C1355`는 이미 1:1 문의했으나 답이 없다고 한다. `E1355`는 다시 1:1 문의를 안내한다. 접속 불가와 무응답은 다른 상태다.
- **반례:** 별도 유튜브 후속반응 70행 중 ‘해결·이해됨’ 26행도 있다. AS 전환은 필요한 전문 진단일 수 있다.
- **해석:** 시도한 문의 채널·진행 상태·다음 확인 항목을 이어받는 문제를 탐색할 수 있다.
- **한계:** 답변 후 반응이 없으면 해결 여부는 모른다. 기존 ‘문의가 안 된다’ 21행에는 무응답·불만 등이 섞일 수 있어 기술적 접속 실패 21건으로 쓰지 않는다.
- **강도:** 제한적. 이관률로 서비스 실패율이나 고객 이탈률을 계산하지 않는다.

### 6) 구독 비용은 금액 계산보다 항목·기간·계약 적용을 이해하는 문제다 — I08·I09·I10

- **공식 조사 추출텍스트:** 2021년 이후 가전 구독·렌탈 경험자 500명의 2025-11-12~21 온라인 패널 조사에서 위약금이 없다고 인지한 응답 157명(31.4%), 위약금 외 추가 비용 발생 가능성을 몰랐다는 응답 139명(27.8%), 월 요금만 강조하고 총비용을 명확히 비교하지 않는 것을 문제로 본 응답 336명(67.2%)이 확인된다.
- **검증 경계:** 보존 PDF 추출텍스트의 문항·기간·대상을 확인하고 비율 산술을 검산했다. PDF 시각 대조와 개별 설문 응답 원자료 재분석은 하지 않았다. 피해구제 2,624건과 설문 500명은 별개 집단이다.
- **조건 선택 문제:** 보존 LG FAQ에는 공기청정기 회수비 39,000원과 2026-03-24 기준·계약서 금액 조건이, 별도 가이드에는 35,000원과 2021-11-05 이후 계약 문구가 있다. 전환 계약일과 실제 계약 적용은 미확인이다.
- **비교 기간 문제:** 과거 Mock C001의 해지 323,400원−이전 80,000원=243,400원은 가정상 일회성 차액이다. 유지 시 미래 구독료·해지 시 대체가전 비용·만기 소유권을 포함한 총경제성은 아니다.
- **해석:** 정산 항목과 미확인 조건을 분리하고 동일 기간의 선택지를 이해하도록 돕는 문제를 탐색할 수 있다.
- **한계:** LG·공기청정기·이사 고객만의 인식 비율이 아니며, 이사가 최대 분쟁 원인이라는 근거도 아니다. Mock은 수요·효과 근거에서 제외한다.

### 7) 근거는 ‘공식 링크’가 아니라 ‘해당 주장에 적용되는 링크’여야 한다 — I12

- **사실:** S03 보존 응답의 TV 파워보드 안내 문맥에는 필터 신청 URL이 붙어 있다. 보존 대상 페이지 본문은 공기청정기·스탠드 에어컨 필터 안내다.
- **해석:** 제품·주장·시점·적용 조건과 근거를 함께 확인하는 문제가 기기 지원과 구독 비용 양쪽에 공통으로 나타난다.
- **다른 설명:** 이 한 사례로 기존 서비스 전체의 정확도나 파워보드 서비스 자체의 진위를 단정할 수 없다.
- **강도:** 보존 기록의 주제 불일치는 충분. 발생 빈도·현재 상태는 미확인.

## 3. 문제 영역별 비교 — 주제 확정이나 순위가 아님

| 문제 영역 | 현재 자료가 제공하는 것 | 주요 반례·제약 | 다음에 필요한 확인 |
|---|---|---|---|
| 기기 이상 후 다음 행동 | 조치 실패·재발·행동 질문 원문 | 영상 안내로 이해하는 사례도 있음; AI 라벨 편향 | 실제 경험자의 판단 과정·현재 지원 경로 |
| 자가 점검 범위·중단 조건 | 수행 중 막힘과 새 이상 자기보고 | 실제 고장·피해·인과 불명 | 제품별 안전 근거·사용성·전문가 확인 |
| 상담 준비·A/S 이력 정리 | 날짜·수리·방문·증빙의 차이가 드러나는 표준질문 | 기존 챗봇도 목록 제공 | 사용자가 무엇을 못 모으고 반복 설명하는지 |
| 구독 비용 이해·조건 적용 | 공식 인식 조사, 보존 안내의 적용 조건 차이 | 계약 원문·현행성·이사 수요 부족 | 고객 계약의 필수 필드·같은 기간 비용 이해 |
| 상담 채널 전환 | 이미 문의했는데 재문의 안내한 사례 | 이관이 적절할 수 있고 무응답≠접속불가 | 상태 구분·대안 채널·이력 전달의 실제 유용성 |

새 주제는 과거 Move Care/AirNavi 제품·페르소나·스택을 그대로 계승해 확정하지 않는다. 근거가 서로 다른 지표를 합산해 기회 규모를 만들지도 않는다.

## 4. 기존 자료만으로 판단할 수 없는 사항

1. 전체 고객 중 문제 발생률·개선 수요·지불 의사·우선 대상 제품.
2. 스마트진단 실제 인지율·이용률·성공률. 온라인 언급이 적다는 사실로 추정할 수 없다.
3. 자가 점검으로 피할 수 있는 AS 규모와 안전성·비용 절감 효과.
4. 상담 대기·채널 이탈·해지·반복 문의의 인과 관계.
