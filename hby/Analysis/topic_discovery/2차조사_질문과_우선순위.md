# 2차 조사 — 핵심 질문과 조사 우선순위

작성일: 2026-11-09

**완료 범위:** 1차 결론의 해석 범위 점검, 문제 후보 3개와 조사 질문 5개 선정. 실제 공개 자료 조사·인터뷰·기존 서비스 재시험은 시작하지 않았다. 메인만 사용했으며 외부 조사·Notion·서브 호출·환경/권한 재확인은 하지 않았다. 기존 파일도 수정하지 않았다.

**제안:** 기기 이상 이후의 다음 행동 판단(A)을 먼저 탐색하고, 상담 준비·이력 전달(B)은 인접하되 별도 문제인지 확인한다. 구독 비용·조건 이해(C)는 공식 조사 근거는 있지만 계약 자료 접근의 제약이 있어 별도 조건부 탐색으로 둔다. 이는 조사 순서이며 주제·제품·기술 스택 확정이 아니다.

## 1. 1차 결론의 적용 범위와 수정 사항

### 1.1 ‘가전 피해구제 감소·품질/A/S 청구 증가’의 정확한 의미

## 2. 탐색할 문제 후보 — 최대 3개

### A. 기기 이상 후, 이미 한 조치와 실행 조건을 반영해 다음 행동을 결정하기 어려움

- **사용자·상황:** 가정용 기기에 이상을 느껴 안내를 찾아보거나 조치를 시도했지만, 증상이 남거나 조작 방법을 몰라 점검 지속·중단·전문가 문의 중 무엇을 할지 정하지 못한 사용자. 특정 브랜드·제품·첫 고장으로 한정하지 않는다.
- **근거:** I02·I06. H160의 조치 후 증상 지속, H6의 설명 후 행동 질문, S02의 리모컨 구분 불가 조건과 조작 안내의 간극.
- **반례:** H40은 설명만으로 이해했다고 답한다. 기존 서비스도 원인 분기·점검 안내·전문가 연결을 제공한다. 실제 전문 진단이 필요한 상황은 설명을 더해도 해결되지 않을 수 있다.
- **핵심 미지수:** 결정이 막히는 이유가 설명/맥락 문제인지, 수리 필요·일정·비용·부품 등 외부 제약인지. 어느 조건까지 안전하게 사용자에게 맡길 수 있는지.
- **추가 가치 확인 여부:** **미확인.** 현재는 일부 원문과 가상 서비스 기록의 단서뿐이다. 자가 해결률·AS 감소를 기대 성과로 확정하지 않는다.
- **유지 기준:** 실제 경험의 시간순 재구성에서 조치 결과·조작 조건의 누락이 행동 결정을 막은 사례가 구체적으로 확인되고, 기존 안내의 조건 반영 범위를 대조할 수 있을 때 유지한다.
- **수정·기각 기준:** 주된 제약이 예약 지연·부품 부족·물리적 고장이라면 ‘설명 부족’ 문제를 수정한다. 기존 채널로 충분히 결정할 수 있고 남는 과제가 확인되지 않거나, 개선에 비공개 진단 데이터/위험 조작이 필수라면 현 범위의 후보를 보류·기각한다.

### B. 재발·추가 상담 때 수리 이력과 증빙을 구분해 전달하기 어려움

- **사용자·상황:** 재발·반복 상담을 겪은 뒤 접수·방문·실제 수리·재발 날짜와 조치 내용을 다시 설명하거나, 보증/후속 처리 상담에 필요한 증빙을 모아야 하는 사용자.
- **근거:** I04·I07. 표준질문 23·24번의 수리/방문/하자 구분, 12번의 구매 증빙 문제, 이미 문의한 채널을 재안내한 리뷰 사례.
- **반례:** 표준답변은 실제 문의 빈도가 아니다. S05는 이미 필요한 증빙 목록을 알려준다. 기존 계정의 수리 이력·상담 이력 관리 기능 전체는 확인하지 않았으며, 이관은 적절한 대응일 수도 있다.
- **핵심 미지수:** 이력을 ‘모으지 못함’, ‘구분하지 못함’, ‘채널 사이에 전달하지 못함’ 중 어디에서 실제 부담이 생기는지. 기관이 보유한 기록으로 이미 해결되는지.
- **추가 가치 확인 여부:** **미확인.** 목록 안내 이후의 확보 상태 관리·이력 연결이 별도 가치인지 검증해야 한다. 교환·환급 판정 수요나 실제 승인 가능성과 동일시하지 않는다.
- **유지 기준:** 실제 경험자의 자료와 행동 기록에서 누락·혼동·재작성 때문에 다음 상담 준비가 막힌 일이 확인되고, 사용자가 동의해 제공할 수 있는 최소 정보만으로 그 부담을 다룰 수 있을 때 유지한다.
- **수정·기각 기준:** 기존 이력 조회/전달로 충분하거나 불편이 실제 처리 지연에만 있다면 수정한다. 필요한 이력이 고객에게도 없고 비공개 사업자 시스템 없이는 검증할 수 없으면 보류한다. A와 같은 ‘다음 행동 판단’ 문제로만 설명된다면 독립 후보로 두지 않고 합친다.

### C. 구독 유지·변경·해지 판단에서 비용 항목과 내 계약의 적용 조건을 이해하기 어려움

- **사용자·상황:** 가전 구독·렌탈의 유지·변경·해지를 검토하면서 정산 항목과 앞으로의 비용을 비교해야 하는 사용자. 이사를 필수 상황으로 삼거나 과거 공기청정기/워시타워 기획을 계승하지 않는다.
- **근거:** I08~I10. 별도 경험자 500명의 위약금 없음 인지 31.4%·추가비용 미인지 27.8%, 과거 보존 안내의 회수비/계약 조건 차이, 일회성 차액과 총경제성 구분.
- **반례:** 공식 조사에서 일부 응답자의 인식 공백이 확인된 것이지 전원이 혼동한 것은 아니다. 현재 계약서·고객 화면·상담이 이미 충분할 수 있고, 과거 안내의 금액 차이가 동일 계약의 오류를 뜻하지 않는다. Mock 비교는 실제 수요 근거가 아니다.
- **핵심 미지수:** 현재 실제 계약을 보아도 혼동하는지, 비교 결과가 선택에 중요한지, 계약 버전·기본요금·비용 항목을 합법적·동의된 방법으로 확보할 수 있는지.
- **추가 가치 확인 여부:** **미확인.** 공식 조사 근거는 상대적으로 직접적이지만 PDF 시각 대조·현재 고객 조건·기존 서비스 대비 비교가 남아 있다.
- **유지 기준:** 실제 검토 경험에서 비용 항목/기간/계약 조건 혼동이 판단을 막았고, 해당 계약에 맞는 근거와 필수 입력을 확보할 수 있을 때 유지한다.
- **수정·기각 기준:** 실제 계약·기존 설명으로 혼동이 해소되고 잔여 문제가 없으면 축소·기각한다. 계약별 핵심 조건에 접근할 수 없어 신뢰할 비교를 할 수 없다면 확정 비용 비교 범위는 보류한다. 근거 없는 추정치로 계속 진행하지 않는다.

## 3. 다음 조사 질문 — 총 5개

아래는 **향후 조사 설계**다. 대상자 확보와 자료 접근은 아직 확정되지 않았으며, 이번에는 모집·검색·실행하지 않았다. 소수 목적 인터뷰에서 나온 결과를 전체 고객 비율로 일반화하지 않는다.

### Q1. 기기 이상 경험에서 다음 행동을 정하지 못한 직접 원인은 무엇이었는가? — A

- **중요한 이유:** ‘정보를 더 주면 해결되는 문제’와 물리적 고장·예약·비용 등 설명으로 해결할 수 없는 제약을 구별한다. 자가 해결을 전제로 질문하지 않는다.
- **적합한 방법:** **실제 경험자 인터뷰.** 증상 인지→찾은 안내→실제로 한 조치→관찰 결과→결정 과정을 회상 가능한 한 건으로 재구성한다.
- **필요 대상·자료:** 실제 기기 이상을 겪고 안내를 찾은 사람. 스스로 이해·해결한 경험자와 상담/수리로 넘어간 경험자를 함께 포함한다. 본인 동의로 비식별한 안내·조치 메모가 있으면 보조 자료로 사용한다. 새 위험 조작은 요구하지 않는다.
- **수정·기각 신호:** 결정 지연이 주로 수리·부품·예약·가격 제약 때문이라면 A의 설명/맥락 문제 정의를 수정한다. 기존 안내로 충분했고 조치 이력 반영에 남는 과제가 확인되지 않으면 A를 보류·기각한다.
- **확보 실패 시:** 현재는 인터뷰 대상이 확보되지 않았다. 공개 댓글만으로 사용자 요구 검증이 끝났다고 대체하지 않는다.

### Q2. 기존 서비스는 이미 한 조치·모르는 조건·보유 이력을 반영해 다음 단계를 안내하는가? — A·B, C의 설명 범위도 참고

- **중요한 이유:** 단순 안내를 추가 가치로 오인하지 않도록, 후보를 유지하기 전에 기존 기능으로 해결되는 범위를 확인한다.
- **적합한 방법:** **기존 서비스 비교.** 동일한 비식별 가상 상황과 정보 제공 순서로 공식 도움말·공개 상담 채널·관련 이력 조회 안내의 범위를 비교한다. 새로운 서비스나 프로토타입은 개발하지 않는다.
- **필요 자료·대상:** ‘모델/조작 조건 미확인’, ‘조치 후 지속’, ‘접수와 수리 혼동’, ‘이미 문의함’의 상황 기록. 실행일·실제 질문·제공 정보·응답·후속 질문·관련 기능 접근 조건을 보존한다. 로그인이나 실제 예약/접수는 별도 허가 없이 하지 않는다.
- **수정·기각 신호:** 기존 서비스가 조건 확인과 결과 연결, 이력 정리까지 충분히 수행하면 A/B의 해당 추가 가치 주장을 기각·축소한다. 공개 채널에서 확인되지 않은 기능은 ‘없음’이 아니라 ‘미확인’으로 남긴다. 일부 응답의 누락을 서비스 전체 실패로 확대하지 않는다.
- **해석 경계:** 기능 관찰은 실제 사용자 편익이나 새 대안의 우수성을 입증하지 않는다. Q1·Q3과 함께 판단한다.

### Q3. 재발·추가 상담을 준비할 때 실제로 다시 모으거나 설명해야 하는 정보는 무엇이며, 무엇이 다음 상담을 막았는가? — B

- **중요한 이유:** ‘증빙 목록이 있다’는 사실과 ‘사용자가 그 목록을 실행·전달할 수 있다’는 사실을 분리하고 B가 A와 별도 문제인지 판단한다.
- **적합한 방법:** **실제 경험자 인터뷰.** 재발 또는 두 번 이상 문의한 실제 한 사건의 이력과 자료 준비 과정을 확인한다. 방문 횟수를 실제 수리 횟수로 치환하지 않는다.
- **필요 대상·자료:** 반복 문의·수리 후 재발을 경험한 사용자. 동의받은 비식별 수리내역·상담 기록·증빙 확보 여부만 필요하며, 주소·연락처·계정·결제번호·제조번호 원문을 수집할 이유는 없다. 기록이 없는 경우도 별도로 구분한다.
- **수정·기각 신호:** 기존 앱/사업자의 기록으로 충분하고 사용자가 이력을 다시 준비하지 않았다면 B를 축소한다. 어려움이 오직 비용/처리 지연이라면 문제를 바꾼다. 정보가 고객에게 없고 접근 가능한 대체 자료도 없으면 검증 범위를 보류한다. A와 구분되는 부담이 없으면 A에 합친다.

### Q4. 실제 구독 유지·변경·해지 검토자는 내 계약의 비용 항목과 동일 기간 비교를 어디에서 이해하지 못했는가? — C

- **중요한 이유:** 일반 인식 설문과 가상 비용 차액을 실제 의사결정 문제로 연결할 수 있는지 확인한다. 단순 ‘비용 안내가 있으면 좋겠다’는 호응만 수요 근거로 삼지 않는다.
- **적합한 방법:** **실제 경험자 인터뷰.** 기존 계약/설명을 처음 보았을 때의 이해, 구분한 비용, 실제 선택에 필요했던 정보를 구체적인 검토 경험에 연결한다.
- **필요 대상·자료:** 실제 유지·변경·해지를 검토한 가전 구독·렌탈 경험자. 동의된 비식별 계약 조건·사업자 견적/안내가 있으면 확인한다. 총기간·의무기간·기본/할인요금·정산 항목·비교 종료시점·대체 비용의 확인/미확인을 나누며 없는 값을 만들어 넣지 않는다.
- **수정·기각 신호:** 기존 계약·안내만으로 정확히 이해했고 남은 문제도 없다면 C를 축소·기각한다. 핵심이 현금 부족·이용 의사 변화 등이라면 ‘정보 이해’ 문제를 수정한다. 이사 상황에서만 문제가 크다는 결과가 나오기 전에는 이사 고객으로 한정하지 않는다.
- **해석 경계:** 인터뷰 자체에서 현재 법적 해지금이나 개인 계약 적용을 확정하지 않는다.

### Q5. 후보 판단에 필요한 기준·입력은 공개 자료와 사용자가 동의해 제공 가능한 정보만으로 확보할 수 있는가? — A·B·C 공통 실행 가능성, 특히 C

- **중요한 이유:** 어려움이 있어도 핵심 데이터가 비공개이거나 적용 범위를 검증할 수 없다면 프로젝트로 검증 가능한 문제 범위를 줄여야 한다. ‘API를 나중에 구하면 된다’는 가정을 차단한다.
- **적합한 방법:** **공개 자료 조사.** 필요한 입력→공개 근거/사용자 확인 가능 자료→적용 범위·버전→미확인/비공개 항목의 접근표를 만든다. 사용자 제공 가능성의 실제 확인은 Q1·Q3·Q4에서 보완한다.
- **필요 자료:** A는 모델별 공식 점검 안내·전문 점검 전환/안전 조건, B는 수리/상담 이력의 고객 열람·내보내기 안내와 증빙 요구, C는 계약 버전·정산 항목·총/의무기간·기본요금·효력일이 있는 공식 안내/공개 계약 예시. 비공개 내부 API·인증정보·타인 문서 획득을 전제로 하지 않는다.
- **수정·기각 신호:** A에서 전문가 진단 없이는 핵심 분기가 불가능하거나 안전 조건을 확인할 수 없으면 진단/조작 안내 범위를 제외한다. B의 핵심 이력에 접근 불가하면 전달/정리 범위를 축소한다. C의 계약별 조건·금액 적용을 확인할 수 없으면 확정 계산 범위를 기각·보류한다. 축소한 범위에 독립적인 고객 가치가 남는지도 다시 판단한다.
- **해석 경계:** 공개 예시가 있다는 것과 실사용자 계약에 접근 가능하다는 것은 다르다. 실제 동의된 자료가 확보되기 전 ‘접근 가능’으로 확정하지 않는다.

점수·가중치·시장 규모는 산정하지 않는다. **자료의 근거 충실도와 조사 착수 용이성은 같은 순위가 아니다.**

### 권장 조사 순서와 판단 관문

1. **먼저 Q2와 Q5의 접근 가능 범위를 좁게 확인하도록 계획한다.** 기존 기능으로 이미 해결되거나 핵심 자료를 확보할 수 없는 가정을 초기에 걸러낸다. 모든 제품·규정을 조사하는 전수 검토로 늘리지 않는다.
2. **사용자 문제 확인은 Q1을 우선한다.** 기기 이상 이후 행동 결정의 실제 장애를 확인한다. 반복 상담/재발 경험이 함께 있는 대상자에게는 동의한 범위에서 Q3을 연결하되, 다른 모집단을 같은 빈도로 합치지 않는다. Q2의 기능 누락만으로 A/B를 채택하지 않는다.
3. **C는 Q5의 계약 필수정보 확보 가능성과 인터뷰 대상 접근을 확인한 뒤 Q4로 진행한다.** 자료 접근이 더 명확하거나 경험자 확보가 먼저 되면 C의 착수 순서는 앞당길 수 있다. 이는 시장성 우위 판정이 아니다.
4. **선정 관문:** 실제 경험에서 확인된 미해결 과제 + 기존 서비스의 확인된 대응 범위 + 핵심 입력의 현실적인 확보 경로가 함께 있어야 후보를 다음 구체화 단계로 넘긴다. 하나가 미확인이면 확정 대신 조건부 유지/범위 축소로 남긴다.
5. **중단 관문:** 대상자나 핵심 자료를 확보하지 못하면 결과는 ‘미확인’이다. 확보 실패를 수요 없음으로 해석하지 않으며, Mock·가상 시나리오만으로 실제 수요 검증을 대체하지 않는다. 작은 목적표본의 반례 역시 모집단 전체의 부재를 증명하지 않는다.
