## A/B/C와 N1/N2/N3는 무엇인가요?

분석 흐름은 **이전 수집 원자료 → I01~I12 인사이트 → A/B/C 문제 가설 → 새 분야 6개 상황 조사 → N1~N3 후보**입니다.

| 구분 | 의미 |
|---|---|
| A | 이미 한 행동과 결과를 연결해 다음 행동을 결정하는 어려움 |
| B | 이력·증빙을 구분하고 정리해 다음 상담에 전달하는 어려움 |
| C | 비용 항목과 자신의 계약에 적용되는 조건을 이해하는 어려움 |
| N1 | 프리랜서의 완료 프로젝트 경력·실적 증빙 준비 |
| N2 | 여행사·OTA 구매 항공권의 취소 조건·비용·환불 진행 확인 준비 |
| N3 | 퇴사 후 임금 미지급 사실·증빙·진정 준비 |

A/B/C는 과거 가전 자료에서 나온 **문제 구조**이며, 반드시 셋 중 하나를 선택해야 하는 최종 주제가 아닙니다. N1~N3는 새 분야의 근거로 재검토한 후보로, A/B/C와 일대일 대응하지 않습니다. 가전 수치를 다른 분야의 수요 규모로 옮기지 않습니다.

현재 보고서의 제안은 **N1·N2 우선 검토, N3 예비 검토**입니다. N1은 기존 프리랜서 실적관리 서비스로 충분한지, N2는 조건 이해가 실제 병목인지, N3는 증빙 준비 자체가 어려운지 확인이 필요합니다.
