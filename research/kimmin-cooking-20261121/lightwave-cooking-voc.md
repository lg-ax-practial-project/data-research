  - [네이버 지식iN](https://kin.naver.com/) — 식품 포장지 번역 검색 및 사진 포함 질문 탐색 결과. 검색어·검색 페이지가 다른 별도 조사.
- 표본 수 (전체): 광파오븐 질문 목록 중복 제거 290건. 포장지 번역 검색 1페이지 30건. 조리 관련 사진 질문 검색 1페이지 34건.
- 유효 건수 (분석에 사용): 광파오븐 질문 본문 확보 273건 (미확보 17건 제외). 포장지 번역 후보 본문 확보 30건. 사진 조사에서는 질문 영역 33건 확인, 1건 미확인.

## 조사 목적
광파오븐 관련 질문에서 조리 설정을 묻는 사례를 파악하고, 식품 포장지 번역과 사진이 포함된 조리 질문의 추가 조사 가능성을 살핀다.

## 주요 발견 (관찰한 사실)
- 본문 확보 273건을 질문당 하나의 주 유형으로 분류한 로컬 결과는 사용법·조리 설정 132건, 고장·이상·수리 33건, 구매·모델 비교 29건, 설치·전력 18건, 청소·관리 15건, 기타·불명확 46건이다. 132/273은 약 48.4%다.
- 별도 포장지 번역 검색 1페이지의 질문 30건은 본문이 확보된 후보이며, 관련성과 유형은 별도 사람 검토가 필요하다.
- 사진 질문 검색 결과 34건 중 자동 확인된 33건에서 질문 영역 이미지가 0건으로 기록됐다. 나머지 1건은 영역을 확인하지 못했다. 수집기 한계와 원문 확인이 필요하다.

## 팀 가설 (관찰과 구분)
포장지에서 조리 조건을 읽고 보유한 광파오븐 모델의 설명서와 대조해 사용자가 설정하도록 도우면 조리 준비 부담을 줄일 수 있다. 실제 모델 호환과 안전 조건을 검증해야 하는 제안이다.

## 프로젝트 반영 포인트
포장지 촬영 → 정보 확인·재촬영 → 모델별 설정 근거 확인 → 사용자의 확인 → 모의 오븐 설정 순서를 검토한다. 실제 기기 연동과 조리 완료는 별도 검증이다.

## 한계 및 추가 조사 필요
분류는 본문 기반 자동 1차 분류로 사람의 정답 검증 결과가 아니다. 검색어·노출 순서와 수집 방식에 편향될 수 있고 고객 전체의 비율이나 기기 사용자 비율을 의미하지 않는다. 포장지·사진 조사는 서로 다른 검색으로 합산할 수 없다. 캡처 및 질문 원문은 개인정보·재배포 조건 확인 전이므로 포함하지 않는다. 로컬 발표자료의 조사 설명과 분류표를 대조해 건수를 재집계했다.
