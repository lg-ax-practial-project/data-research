# 광파오븐과 조리 질문 조사 워크플로

- 조사자: 김민
- 조사일: 2026-11-19 (워크플로 파일 수정일 기준)
- 출처:
  - [네이버 검색 API](https://developers.naver.com/docs/serviceapi/search/) 및 [네이버 지식iN](https://kin.naver.com/) — 관련 워크플로의 검색·질문 수집 대상.
  - [SerpApi](https://serpapi.com/), [YouTube Data API](https://developers.google.com/youtube/v3) — 일부 버전의 외부 검색 및 수집 대상.
- 표본 수 (전체): 워크플로 JSON 21개. 데이터 표본 수와는 별개.
- 유효 건수 (분석에 사용): 해당 없음. 버전별 기능과 실행 가능성은 검증 전.

## 조사 목적
광파오븐 사용과 조리법 질문을 탐색하기 위해 작성한 n8n 워크플로의 작업 이력을 공유한다.

## 주요 발견 (관찰한 사실)
`n8n/`에는 광파오븐 검색·공개 본문 탐색 및 지식iN 질문·포장지·사진 질문 수집 버전이 있다. 이름의 수정·안정화 표현은 작업 당시 버전 구분이며 실제 동작을 보증하지 않는다. 기존 집계 복구용 파일은 내장 데이터 검토가 추가로 필요해 제외했다.

## 팀 가설 (관찰과 구분)
없음. 이 문서는 조사 자동화 작업의 기록이다.

## 프로젝트 반영 포인트
워크플로를 가져오기 전 노드와 외부 서비스 설정을 살펴보고 개인의 인증정보를 별도로 설정한다. API 호출 시 사용량이나 비용이 발생할 수 있다.

## 한계 및 추가 조사 필요
공유본 21개에 대해 JSON 구조, 고정 실행 데이터, 인증정보 참조 및 일부 키 패턴을 검사했다. 키 입력란의 확인된 값은 예시 값이었다. 자동 검사로 모든 민감정보를 검출할 수는 없다. n8n 가져오기, 실제 실행과 수집 결과 재현은 이번에 검증하지 않았다. 원문 수집과 전송 및 재배포는 각 출처의 권한과 조건을 확인해야 한다.
