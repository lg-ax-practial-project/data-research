## 조사 목적

한국 중심으로 코로나 전·중·후 판매·보유·수출입과 관심·구매 고려 관련 지표를 모은다. 자료별 기간·분모를 유지한다.

## 주요 발견 (관찰한 사실)

- S01: LG 인공지능쿡 탑재 광파오븐의 2020년 1~8월 판매량은 전년 동기보다 약 30% 증가. 전체 광파오븐 시장의 증가율은 아니다.
- S03: 다나와 복합형 오븐 판매량은 2022년 전년 대비 28% 증가. 광파 외 가열 방식도 포함한다.
- S07: GfK 전자레인지의 2022년 매출은 전년 대비 10% 증가. 판매수량 성장과 구분한다.
- S05·S06: 갤럽의 코로나 이전 및 2021년 조사 소개에서 전자레인지 보유 응답률은 96%→97%, 오븐은 22%→21%. 1%p 변화의 통계적 유의성은 검증하지 않았다.
- S04: 2021년 에너지패널 가구당 보유대수 추정은 전자레인지 0.76대, 전기오븐 0.02대, 광파오븐 0.04대. 구매율·가구 보유율로 치환하지 않는다.
- S09: 2021년 가전 전반 구매 시 사이즈 중요도는 전년 대비 4.8%p 상승. 두 제품 개별 관심도는 아니다.

## 팀 가설 (관찰과 구분)

광파오븐의 편의 기능과 공간 활용 가치가 선택에 영향을 줄 수 있다는 가설은 가능하다. 이 자료만으로 전자레인지 대체, 조리 설정 불편 빈도, 조리 에이전트 사용 의향을 입증할 수는 없다.

## 프로젝트 반영 포인트

발표에는 특정 제조사 판매량, 유통채널 내 점유율, 가구 보유 응답, 통관액을 구분해 인용한다. 수입금액 증가를 소비자 구매자 수 증가로 바꾸어 설명하지 않는다.

## 한계 및 추가 조사 필요

- 광파오븐 대 전자레인지의 전국 연간 판매량·매출액·구매 가구 비율을 동일 기준으로 직접 비교한 공개 시계열은 미확보.
- 광파오븐의 독립 수출 HS 코드를 확인하지 못함. HS851650이나 넓은 오븐류 HS851660 전체를 광파오븐 수출로 간주하지 않음.
- 네이버·Google의 2018~2024년 월별 관심도 실측값 미확보. Google Trends 웹 열람 불가, 브라우저 호스트 연결 불가. API 인증 정보 미제공.
- 2019·2020·2022·2023년 에너지패널 PDF는 약32~77MB로 열람 도구 크기 제한. 원문 파일 자체를 내려받아 저장한 상태가 아님.
- PDF 표는 검색 도구의 텍스트 추출로 확인. 이미지 열람 실패 자료는 시각 검증을 완료했다고 표시하지 않음.
- WITS 2019년 한국 수출 페이지 열람 실패. 2019년 수출액은 S14의 반올림값만 확보; 수량을 추정해 채우지 않음.
