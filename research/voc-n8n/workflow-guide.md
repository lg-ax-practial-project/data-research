  - [네이버 검색 API](https://developers.naver.com/docs/serviceapi/search/), [YouTube Data API](https://developers.google.com/youtube/v3), [SerpApi](https://serpapi.com/), [OpenAI API](https://platform.openai.com/docs/) — 워크플로별 검색 또는 AI 분류 연동 대상. 모든 파일이 모든 서비스를 사용하는 것은 아님.

- 유효 건수 (분석에 사용): 해당 없음.

## 조사 목적
세탁과 조리 고객 의견을 검색·수집하고 일부 결과를 AI로 분류하는 작업의 설정과 흐름을 공유한다.

## 주요 발견 (관찰한 사실)
- `laundry/`: 네이버·YouTube 기반 검색, 아하 검색, 두 가지 고민 분석, 여섯 유형 분류 등의 기존 버전.
- `cooking/`: 아하 또는 Google 검색과 AI 분류에 관한 기존 버전.
- 파일 이름에 수정·오류 등의 표현이 있는 것은 작업 당시의 구분이며, 정상 동작이나 최종본을 보증하지 않는다.

## 팀 가설 (관찰과 구분)
없음. 이 문서는 조사 자동화 도구의 목록이다.

## 프로젝트 반영 포인트
각 JSON을 n8n에 가져와 노드와 연결을 검토한다. API 키는 각 사용자가 별도로 설정하며 저장소에 기록하지 않는다. 일부 워크플로는 실행 시 외부 검색·모델 API 사용량과 비용이 발생한다. 원문 전송과 보관은 서비스의 이용 조건을 확인한다.

## 한계 및 추가 조사 필요
공유본에서 인증정보 노드 참조와 고정 실행 데이터가 없고 주요 키 입력란이 예시 값인 것을 확인했다. 자동 패턴 검사는 모든 비밀정보를 탐지하지 못한다. n8n 가져오기·실행 및 출력 재현은 이번에 검증하지 않았다. 수집 결과 113개가 내장된 조리 기존검색복구 버전은 제외했다. 검색 결과와 수집 원문은 이용 및 재배포 조건 확인 전 별도로 공개하지 않는다.
