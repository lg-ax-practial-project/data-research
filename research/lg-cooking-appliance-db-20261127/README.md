- 조사일: 2026-11-27 (한국 시간)

- 표본 수 (전체): 공개용 DB에 수록한 모델 코드 1,247개
- 유효 건수 (분석에 사용): 모델 코드 1,247개, 공개 사용설명서가 확인된 모델 669개

## 조사 목적

고객이 기기의 모델 라벨을 촬영했을 때, 조리 에이전트가 확인된 모델 코드로 공식 사용설명서를 찾아 해당 모델의 기능 안내 근거로 사용할 수 있는지 확인합니다.

## 주요 발견 (관찰한 사실)

| 제품군 | 모델 코드 | 공개 설명서 확인 | 공개본 미확인 | 대조한 판매 목록 |
|---|---:|---:|---:|---|
| 전자레인지 | 830 | 279 | 551 | LG 사업자몰 22개 모두 확인 |
| 인덕션·하이브리드 | 216 | 207 | 9 | LG 공식몰 인덕션 30개와 하이브리드 7개 모두 확인 |
| 광파오븐 | 201 | 183 | 18 | LG 공식몰 및 사업자몰의 동일한 13개 모두 확인 |
| 합계 | 1,247 | 669 | 578 | 서로 다른 72개 모델 모두 확인 |

하이브리드 63개는 인덕션 화구가 있는 제품으로 분류했습니다. 광파 조리 기능을 확인한 빌트인 모델 4개는 광파오븐에 포함했습니다. 모델별 설명서 연결 1,433건과 공식 자료 URL 431개를 확인했습니다. 광파오븐 설명서 중 시리즈명으로 공개된 5건은 모델 단위 합계에서 제외하고 별도 색인에 담았습니다.

## 팀 가설 (관찰과 구분)

모델 코드가 확정된 경우 모델별 문서 원본으로 연결하면, 사용자가 설명서를 찾아 모델 적용 여부를 비교하는 부담을 줄일 수 있습니다. 실제 검색 시간이나 AI 안내 정확도는 이번 조사에서 측정하지 않았습니다.

## 프로젝트 반영 포인트

[제품 DB JSON](product-db.json)의 `products_by_model`에서 LG 모델 코드로 조회합니다. 예를 들어 `products_by_model["MW23GD"]`는 해당 모델의 제품군, 근거 링크와 사용설명서 목록을 반환합니다.

| 필드 | 의미 |
|---|---|
| `observed_on` | 국내 수집본을 확인한 날짜 |
| `product_category`, `product_type` | 제품군과 세부 유형. 하이브리드 및 광파 조리 빌트인을 구분 |
| `observed_in_catalogs` | 대조한 목록에 표시된 경우 `sources`의 키를 기록. 빈 배열은 이 목록들에서 확인되지 않았다는 뜻 |
| `reference_urls` | LG 고객지원 및 필요한 경우 제품군 확인에 쓰인 LG 출처 |
| `manual_status` | `found`는 연결한 공식 자료가 있음. `not_found`는 조사 범위에서 공개 자료를 찾지 못함 |
| `manuals` | 자료별 공식 URL, 형식, 언어, LG가 표시한 게시일과 확인한 PDF 쪽수. 게시일이 표시되지 않은 자료는 null |
| `series_manuals` | 광파오븐 시리즈 공용 자료. 모델명에 그대로 적용하기 전 설명서에서 모델 범위를 확인해야 함 |

모델 코드의 하이픈을 보존합니다. 하이픈을 제거하면 동일해지는 코드 묶음 11개를 확인했으므로 모델 번호가 모호하면 사용자 확인을 받는 흐름이 필요합니다. 이 DB를 기준으로 우선 검증할 예시는 `MW23GD`, `BEI3QKBLOE`, `MLJ39PR`입니다.

## 한계 및 추가 조사 필요

- LG 국내 고객지원 검색은 한 번에 최대 120개를 반환하므로 모델명 검색어를 나누어 조회했습니다. 두 제품군에 섞여 있던 일부 결과는 제품 페이지나 설명서로 분류를 확인했습니다. 레코드는 수집된 모델 코드 기준이며 국내 전체 출시 이력이나 판매 중 재고를 뜻하지 않습니다.
- 모델 코드 유일성, 공식 도메인과 자료 형식, 설명서 상태와 연결 수, 확인한 판매 목록의 모델 포함 여부를 검증했습니다. 자료 URL의 접근과 파일 형식은 수집 시 확인했으며 모델별 설명서 내용 전체를 대조하지는 않았습니다. 정격, 용량, 조리 모드, 가격 등 사양은 이번 데이터 범위에 포함되지 않습니다.
- 공개용 파일에는 모델 코드, 정리한 메타데이터와 LG 원본 URL을 실었습니다. 설명서 PDF·ZIP, 별도 쿡북, 제품 이미지, 고객 데이터는 원본 저장 위치에 보관하거나 이번 공유 범위에서 제외했습니다.
